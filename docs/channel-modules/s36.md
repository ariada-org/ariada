# S36: winget + Scoop manifests

The proposed Windows distribution would add a YAML manifest to the Windows Package Manager community repository and JSON manifests to a Scoop bucket so command-line users could install an existing Ariada release.

## Boundary

No winget or Scoop manifest is present, and manifests cannot precede a stable downloadable executable with verified checksums; they would describe installation only, not add functionality or imply Microsoft, Scoop, or compliance endorsement.

## Roles

- Windows package-manifest contributor
- Windows developer-tooling administrator

## Use cases

- An administrator would install a pinned CLI through winget or Scoop and verify its path and upgrade behavior on a clean Windows environment.
- A manifest contributor would update release URLs, architecture selectors, installer switches, and hashes before repository validation and review.

## Installation

Not installable: winget + Scoop manifests has no qualifying public implementation or package in the canonical Ariada repository.
