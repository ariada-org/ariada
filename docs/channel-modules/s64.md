# S64: Statamic addon

The proposed Statamic addon would be a Composer-installed Marketplace product integrated with the control panel, allowing Laravel-based site teams to review Live Preview output for entries and collections.

## Boundary

No Statamic addon or Marketplace listing is delivered; a future addon would inspect configured previews while leaving blueprints, content repositories, revisions, publication, and template edits under Statamic and Git control.

## Roles

- Statamic control-panel publisher
- Laravel content-site developer

## Use cases

- A publisher would open an entry in Live Preview, test responsive page states, and inspect findings before saving a publish action.
- A developer would assess Composer constraints, addon service-provider behavior, control-panel permissions, and Marketplace licensing before staging use.

## Installation

Not installable: Statamic addon has no qualifying public implementation or package in the canonical Ariada repository.
