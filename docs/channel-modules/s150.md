# S150: Saleor app

Saleor apps connect to a headless commerce platform through dashboard installation, GraphQL permissions, and webhooks while storefronts are separate clients; a planned Saleor app would coordinate Ariada review of explicitly registered storefront deployments.

## Boundary

The app would not infer accessibility from Saleor's GraphQL schema or audit an unspecified frontend. It would not mutate products, process checkout, request unnecessary permissions, or imply that an installable Saleor app exists.

## Roles

- Saleor platform operator
- Headless storefront engineer

## Use cases

- The storefront engineer would register a preview deployment and review Ariada evidence for product variants, checkout errors, and account dialogs before a release.
- The platform operator would use channel and deployment metadata to route a finding to the correct regional storefront instead of treating the Saleor backend as the rendered surface.

## Installation

Not installable: Saleor app has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence

- No qualifying public implementation evidence is declared and present on the canonical public tree.
