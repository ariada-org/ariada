# S69: Gitea/Forgejo Action

The planned Gitea/Forgejo Action would be a tagged action repository with an `action.yml` contract, consumed by compatible Actions runners in self-hosted forges to scan declared web artifacts.

## Boundary

No action repository or release is delivered; a future action would not administer the forge or runner, would require operators to authorize targets and pin dependencies, and would leave checks and deployment decisions to the workflow.

## Roles

- Forgejo repository workflow owner
- Self-hosted Actions runner operator

## Use cases

- A workflow owner would reference a commit-pinned action after the site build and publish its report with the run artifacts.
- A runner operator would audit action source, container or runtime dependencies, network access, token exposure, and Forgejo compatibility before enabling it.

## Installation

Not installable: Gitea/Forgejo Action has no qualifying public implementation or package in the canonical Ariada repository.
