# S140: Softr integration

Softr turns data sources into portal and application pages composed from blocks, lists, forms, and role-gated views; a planned Softr integration would give no-code operators Ariada evidence for the published experience users actually receive.

## Boundary

The connection would not access unauthorized Softr user roles or infer hidden states without supplied test access. It would not change blocks, records, permissions, or domains, and it would not indicate a working Ariada app.

## Roles

- No-code portal operator
- Member-experience tester

## Use cases

- Before inviting customers to a Softr portal, the tester would review sign-in, list filtering, empty states, and form errors under an appropriate member account.
- When an operator publishes a new Softr block, they would compare desktop and mobile output and return accessibility defects to the block configuration or source data.

## Installation

Not installable: Softr integration has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence

- State: Planned
- Updated from evidence: Not available
- No qualifying public implementation evidence is declared and present on the canonical public tree.
