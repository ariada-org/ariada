# S214: Campaign Monitor landing/email scan recipe

Campaign Monitor teams create templates, campaigns, and automated journeys whose HTML is previewed and tested before sending; a planned landing/email scan recipe would give email producers a repeatable accessibility review alongside client previews.

## Boundary

The recipe would not send campaigns, access lists, alter journeys, or replace testing in real email clients and assistive technologies. It would not imply a Campaign Monitor app or API implementation.

## Roles

- Campaign Monitor email producer
- Journey-message quality reviewer

## Use cases

- Before a Campaign Monitor journey is activated, the reviewer would inspect each message with realistic personalization and verify meaningful order when CSS or images are unavailable.
- The producer would compare test sends in representative clients and use Ariada HTML evidence as one input, not as a substitute for inbox behavior.
