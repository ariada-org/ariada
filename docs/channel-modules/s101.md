# S101: Gradle plugin (Java/Kotlin)

A future Gradle plugin would be published with a plugin ID and marker to the Gradle Plugin Portal, adding cache-aware tasks that Java or Kotlin web builds configure with generated HTML or test URLs.

## Boundary

No Gradle plugin or portal entry exists; a future task would not infer UI from JVM classes, would require declared rendered targets, avoid undeclared network and output effects, and leave task wiring and build failure thresholds to consumers.

## Roles

- Gradle convention-plugin engineer
- Kotlin web delivery quality lead

## Use cases

- A convention-plugin engineer would wire an Ariada task after documentation or frontend asset generation and declare its inputs and report outputs.
- A delivery lead would review configuration-cache support, task isolation, Gradle and JVM compatibility, plugin marker provenance, and Portal metadata before adoption.

## Installation

Not installable: Gradle plugin (Java/Kotlin) has no qualifying public implementation or package in the canonical Ariada repository.
