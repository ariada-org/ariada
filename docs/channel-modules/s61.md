# S61: Strapi plugin

A future Strapi plugin would be distributed through npm and the Strapi Marketplace, adding an administration view or entry action for content managers to analyze a frontend preview backed by a Strapi record.

## Boundary

No Strapi plugin or Marketplace listing exists; a future implementation would require an application-specific preview URL, would respect Strapi roles and permissions, and would not mutate records, publish entries, or scan JSON as though it were UI.

## Roles

- Strapi content manager
- Headless CMS platform administrator

## Use cases

- A content manager would select a draft collection entry, open the consumer site's preview, and inspect findings before publication.
- A platform administrator would verify admin/server plugin components, permissions, compatibility, hosting, and Marketplace metadata before installation.

## Installation

Not installable: Strapi plugin has no qualifying public implementation or package in the canonical Ariada repository.
