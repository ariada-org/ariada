# S62: Craft CMS plugin

The planned Craft CMS plugin would be a Composer package and Craft Plugin Store product, providing control-panel actions for editors and project developers to review entry previews rendered through Craft templates.

## Boundary

No Craft package or Plugin Store entry is available; a future plugin would honor element permissions and preview tokens, would not save or publish entries, change project config, or claim that every frontend state has been tested.

## Roles

- Craft CMS content producer
- Craft project configuration developer

## Use cases

- A producer would open an unpublished entry's Live Preview and review issues before applying it to a propagation site.
- A project developer would evaluate Composer requirements, control-panel permissions, preview-token handling, and Plugin Store support before installation.

## Installation

Not installable: Craft CMS plugin has no qualifying public implementation or package in the canonical Ariada repository.
