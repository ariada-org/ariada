# S19: Vite plugin

The source-delivered Vite plugin analyzes HTML served during Vite development and emitted by production builds, placing findings in the workflow used by frontend developers and build-release reviewers.

## Boundary

The delivered source targets Vite 5 or newer development and build output without establishing npm publication; it does not cover native UI, inaccessible authenticated states that were never rendered, or final compliance judgment.

## Roles

- Vite application developer
- Frontend artifact release reviewer

## Use cases

- A developer opens a locally served route, inspects findings while implementing its layout, and decides which source changes are appropriate.
- A release reviewer scans the production HTML artifact and evaluates the report before the Vite deployment is promoted.

## Installation

Source-delivered, not registry-published: build @ariada-org/vite-plugin with `pnpm --dir packages/ariada-vite-plugin run build`; no npm release is claimed.
