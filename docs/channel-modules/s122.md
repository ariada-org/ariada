# S122: Marvel integration

Marvel organizes design screens into linked prototypes, review comments, user tests, and developer implementation review; a proposed Marvel integration would give product discovery teams an Ariada evidence path for those shared prototype objects.

## Boundary

The planned connection would analyze only accessible preview material supplied for review. It would not alter Marvel hotspots or source artwork, observe all user-test behavior, certify the built product, or suggest current integration availability.

## Roles

- Rapid-prototyping designer
- Product discovery facilitator

## Use cases

- Before distributing a Marvel prototype test link, the facilitator would review the opening task and completion screen for keyboard reachability and understandable controls.
- At developer implementation review, the designer would use Ariada evidence to annotate a Marvel screen whose icon-only action lacks a documented accessible name.

## Installation

Not installable: Marvel integration has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence

- No qualifying public implementation evidence is declared and present on the canonical public tree.
