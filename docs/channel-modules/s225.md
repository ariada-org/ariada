# S225: Sitecore integration

Sitecore authors manage content items through workflow while developers compose renderings, layouts, and data sources into pages previewed in Experience Editor; a proposed integration would attach Ariada evidence to the item, language, and presentation under review.

## Boundary

The integration would not approve workflow, change items or presentation details, publish content, or assume authoring preview equals every delivery environment. It would not imply a Sitecore Marketplace module.

## Roles

- Sitecore content approver
- Presentation-layer solution architect

## Use cases

- Before a Sitecore item leaves workflow, the approver would review its page rendering in the correct language, device layout, and personalization context.
- The solution architect would sample pages using a changed rendering and map common Ariada findings to that component rather than returning each item to authors.

## Installation

Not installable: Sitecore integration has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence

- State: Planned
- Updated from evidence: Not available
- No qualifying public implementation evidence is declared and present on the canonical public tree.
