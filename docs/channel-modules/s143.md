# S143: Tilda integration

Tilda publishers combine standard blocks and custom Zero Blocks into project pages, forms, and responsive layouts; a planned Tilda integration would provide Ariada evidence to designers reviewing a page before domain publication.

## Boundary

The adapter would review rendered output, not the visual canvas itself, and would not edit block settings, Zero Block geometry, forms, or publication status. It would not claim support exists beyond this plan.

## Roles

- Tilda art director
- Editorial page publisher

## Use cases

- Before publishing a Tilda Zero Block hero, the art director would review absolute-positioned content at several breakpoints for reading order and loss of text.
- The publisher would test a Tilda form through validation and success states, then use Ariada evidence to revise labels and instructions before campaign launch.

## Installation

Not installable: Tilda integration has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence

- State: Planned
- Updated from evidence: Not available
- No qualifying public implementation evidence is declared and present on the canonical public tree.
