# S59: Contentful app

The planned Contentful App Framework app would be installed into an organization or space and placed in entry, sidebar, or dialog locations so content teams could review a rendered preview tied to an entry.

## Boundary

No Contentful app or Marketplace listing exists; a future app would access only installed locations and permitted fields, require a project-provided preview endpoint for rendered analysis, and would not change or publish entries.

## Roles

- Contentful space content editor
- Contentful app installation administrator

## Use cases

- An editor would open a landing-page entry, launch its environment-specific preview, and inspect findings before changing the entry's workflow status.
- An administrator would review app locations, field access, parameters, hosting origin, and Marketplace disclosures before installing it in a production space.

## Installation

Not installable: Contentful app has no qualifying public implementation or package in the canonical Ariada repository.
