# S155: nopCommerce plugin (.NET)

nopCommerce plugins extend a .NET store's administration and shopper experience and may be distributed through its marketplace; a future nopCommerce plugin would surface Ariada evidence for pages chosen by store owners and solution developers.

## Boundary

The plugin would not edit Razor views, products, customers, or checkout settings, and would not promise compatibility with every theme or plugin combination. It would not imply a marketplace listing or compiled deliverable.

## Roles

- nopCommerce solution developer
- .NET store acceptance tester

## Use cases

- Before deploying a nopCommerce theme customization, the tester would review account registration, product attributes, cart, and checkout in a non-production store.
- The solution developer would reproduce each finding with the active widget and payment plugins documented, separating host-theme defects from injected markup.

## Installation

Not installable: nopCommerce plugin (.NET) has no qualifying public implementation or package in the canonical Ariada repository.
