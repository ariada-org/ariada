# S154: Spree extension (Ruby)

Spree extensions augment the Ruby commerce engine, whose host application supplies storefront views, products, carts, and checkout; a proposed Spree extension would let engineering teams collect Ariada evidence from concrete application routes.

## Boundary

The extension would not assume all Spree applications share templates or frontend behavior. It would not alter Rails code, orders, or configuration, claim automatic remediation, or represent a released Ruby gem.

## Roles

- Spree application engineer
- Ruby commerce QA specialist

## Use cases

- Within a staging Spree store, the QA specialist would review product configuration and checkout failures using seeded data rather than risking production orders.
- The application engineer would correlate a finding with the overriding view or frontend component in that particular Spree host before changing code.

## Installation

Not installable: Spree extension (Ruby) has no qualifying public implementation or package in the canonical Ariada repository.
