# S97: Ruby gem + Rails engine

A future RubyGem would include a Railtie or engine that adds explicit rake tasks or test helpers for Rails teams to analyze rendered views and system-test routes.

## Boundary

No gem or Rails engine is published; a future integration would rely on application fixtures and rendered responses, would not change Active Record data, routes, views, or assets, and would not replace browser-based interaction testing.

## Roles

- Rails application engineer
- View-layer accessibility test reviewer

## Use cases

- A Rails system test would render a checkout validation state and invoke Ariada on the page before the test transaction rolls back.
- A reviewer would evaluate engine isolation, Rails version support, task names, asset behavior, gem provenance, and release documentation before adding it to the bundle.

## Installation

Not installable: Ruby gem + Rails engine has no qualifying public implementation or package in the canonical Ariada repository.
