# S157: Jira app (Atlassian Marketplace)

Jira apps distributed through Atlassian Marketplace can add issue panels, project pages, fields, and workflow actions; a planned Jira app would turn Ariada findings into traceable work for accessibility leads and delivery teams.

## Boundary

The app would not scan a product merely because its work is tracked in Jira, auto-close findings, change workflows without authorization, or claim Marketplace approval. Human owners would retain severity and acceptance decisions.

## Roles

- Accessibility defect coordinator
- Jira project administrator

## Use cases

- After reviewing a release URL, the coordinator would create a Jira issue with reproducible evidence, affected route, user impact, and the owning component rather than a context-free score.
- The project administrator would configure deduplication and status mapping so repeated Ariada observations update the correct issue without disrupting the team's workflow scheme.

## Installation

Not installable: Jira app (Atlassian Marketplace) has no qualifying public implementation or package in the canonical Ariada repository.
