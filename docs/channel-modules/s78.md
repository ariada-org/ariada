# S78: Eclipse plugin (Marketplace)

The planned Eclipse integration would be an OSGi bundle and feature distributed from a p2 update site and optionally listed in Eclipse Marketplace, serving enterprise web developers inside Eclipse-based IDEs.

## Boundary

No bundle, update site, or Marketplace listing is delivered; a future plugin would report on selected resources or configured pages, would not rewrite workspace files automatically, and would remain subject to Eclipse compatibility and signing review.

## Roles

- Eclipse web-tools developer
- Enterprise IDE provisioning administrator

## Use cases

- A developer would scan a selected web resource and triage markers in the Problems view before submitting a change.
- A provisioning administrator would install the feature from a test p2 site and review signatures, dependencies, permissions, and target-platform compatibility.

## Installation

Not installable: Eclipse plugin (Marketplace) has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence

- State: Planned
- Updated from evidence: Not available
- No qualifying public implementation evidence is declared and present on the canonical public tree.
