# S186: pa11y-compatible adapter (drop-in for pa11y users)

pa11y users configure URLs, actions, runners, thresholds, and reporters around a familiar command-line result shape; a planned pa11y-compatible adapter would let those teams consume Ariada evidence without pretending to be pa11y itself.

## Boundary

Compatibility would cover a documented input and output subset, not every pa11y option, action script, runner, or exit-code assumption. No drop-in package or behavioral parity would be claimed before implementation and conformance evidence.

## Roles

- pa11y pipeline owner
- CLI migration assessor

## Use cases

- The migration assessor would compare proposed adapter output against existing pa11y JSON consumers and document unsupported fields before changing a CI pipeline.
- A pipeline owner would test authenticated action sequences and threshold behavior in a sandbox rather than assuming command-line substitution is risk free.

## Installation

Not installable: pa11y-compatible adapter (drop-in for pa11y users) has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence

- State: Planned
- Updated from evidence: Not available
- No qualifying public implementation evidence is declared and present on the canonical public tree.
