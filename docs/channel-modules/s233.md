# S233: Stencil output target

Stencil output targets transform compiled web components into distributions such as custom-elements bundles, framework bindings, or generated documentation; a planned output target would emit Ariada review metadata for a rendered component harness.

## Boundary

Compiler output alone cannot be accessibility-tested without meaningful markup, states, and a host page. The target would not publish packages, modify components, or imply an implemented Stencil output-target package.

## Roles

- Stencil compiler pipeline owner
- Web-component distribution reviewer

## Use cases

- The pipeline owner would render compiled Stencil components in a controlled harness with representative properties and states before collecting Ariada evidence.
- The distribution reviewer would attach findings to the exact component build and output flavor while requiring consuming frameworks to test application-level composition separately.

## Installation

Not installable: Stencil output target has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence

- State: Planned
- Updated from evidence: Not available
- No qualifying public implementation evidence is declared and present on the canonical public tree.
