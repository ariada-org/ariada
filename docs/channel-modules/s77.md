# S77: Emacs package (MELPA)

A future Emacs Lisp package would be distributed through MELPA or MELPA Stable, giving web developers commands, compilation output, or Flymake-style findings for buffers they choose to analyze.

## Boundary

No Emacs package or MELPA recipe exists; a future package would call an explicitly configured Ariada executable or endpoint, would not change buffers without consent, and would not make a source-buffer check equivalent to browser validation.

## Roles

- Emacs web-mode developer
- MELPA recipe and package reviewer

## Use cases

- An Emacs user would invoke a scan on the current template and navigate locations through a compilation or diagnostic buffer.
- A MELPA reviewer would run package lint, inspect dependencies and autoloads, verify repository tags, and assess supported Emacs versions before inclusion.

## Installation

Not installable: Emacs package (MELPA) has no qualifying public implementation or package in the canonical Ariada repository.
