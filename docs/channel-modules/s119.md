# S119: Zeplin extension

A proposed Zeplin extension would place Ariada findings beside the screens, component specifications, and implementation review annotations that product designers share with implementation teams in Zeplin projects and styleguides.

## Boundary

The extension would only associate submitted design or preview evidence with review findings. It would not edit a Zeplin screen, infer the accessibility of the eventual coded interface, approve a implementation review, or represent an available Ariada implementation.

## Roles

- Design review completion lead
- Frontend implementation reviewer

## Use cases

- Before marking a Zeplin screen ready for development, a implementation review lead would review text alternatives, contrast decisions, and documented interaction states against Ariada evidence.
- While publishing a shared Zeplin styleguide, a frontend reviewer would trace a finding to the affected component specification and return a concrete question to the designer.

## Installation

Not installable: Zeplin extension has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence

- State: Planned
- Updated from evidence: Not available
- No qualifying public implementation evidence is declared and present on the canonical public tree.
