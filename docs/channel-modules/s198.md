# S198: MODX extra

MODX extras package plugins, snippets, templates, chunks, and manager integrations for sites whose published pages are assembled from Resources and Elements; a proposed MODX extra would surface Ariada evidence for site builders.

## Boundary

The extra would not rewrite Resources or Elements, install transport packages, change manager permissions, or guarantee arbitrary extras and themes. It would not imply publication in the MODX Extras repository.

## Roles

- MODX site builder
- Resource-tree content editor

## Use cases

- A site builder would review pages generated from each important MODX template after changing a shared chunk, catching defects propagated across the Resource tree.
- The content editor would use route-specific Ariada evidence to correct headings, links, and media fields without editing unrelated template logic.

## Installation

Not installable: MODX extra has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence

- State: Planned
- Updated from evidence: Not available
- No qualifying public implementation evidence is declared and present on the canonical public tree.
