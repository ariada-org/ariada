# S38: PostCSS plugin

The planned PostCSS plugin would be an npm package inserted into a CSS processing chain, where stylesheet authors and build engineers could receive findings tied to declarations and selectors visible in the PostCSS AST.

## Boundary

No PostCSS plugin exists; CSS-only inspection cannot establish text-background contrast, focus behavior, DOM semantics, or cascade outcomes without rendered context, so a future plugin would report only defensible stylesheet evidence and would not rewrite rules silently.

## Roles

- CSS architecture lead
- PostCSS pipeline engineer

## Use cases

- A stylesheet team would flag a risky focus-outline removal during its existing PostCSS build and review the declaration in source.
- A pipeline engineer would test plugin order, source maps, syntax extensions, warning output, and npm release metadata before enabling it across projects.

## Installation

Not installable: PostCSS plugin has no qualifying public implementation or package in the canonical Ariada repository.
