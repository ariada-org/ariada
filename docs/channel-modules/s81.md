# S81: Raycast extension

A future Raycast extension would be a set of commands distributed through the Raycast Store, allowing macOS users to submit a URL or selected local artifact to Ariada from the launcher.

## Boundary

No Raycast extension or Store pull request exists; a future command would analyze only explicit input through a documented local tool or endpoint, would not inspect arbitrary browser tabs or desktop UI, and would not hide network or credential requirements.

## Roles

- Raycast workflow power user
- Frontend quality triage specialist

## Use cases

- A specialist would invoke a Scan URL command for a staging page and open the resulting report from Raycast.
- An extension contributor would review command metadata, preferences, secrets, error states, screenshots, and Store repository checks before submission.

## Installation

Not installable: Raycast extension has no qualifying public implementation or package in the canonical Ariada repository.

- State: Planned
- Updated from evidence: Not available
- No qualifying public implementation evidence is declared and present on the canonical public tree.
