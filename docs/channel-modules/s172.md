# S172: Pulumi component

Pulumi component resources package related infrastructure declarations inside language-based stacks, previews, and updates; a planned Pulumi component would coordinate an Ariada review endpoint with an application's deployment metadata.

## Boundary

The component would not make accessibility a cloud resource property, mutate the application, or conceal asynchronous review behind a successful stack update. It would remain unimplemented until a real package and contract are evidenced.

## Roles

- Pulumi component author
- Cloud stack release owner

## Use cases

- After a Pulumi stack exposes a preview URL, the release owner would request Ariada evidence tagged with stack and environment rather than embedding findings in secret-bearing state.
- The component author would design outputs that link to asynchronous review results while allowing infrastructure preview and accessibility approval to remain separate decisions.

## Installation

Not installable: Pulumi component has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence

- State: Planned
- Updated from evidence: Not available
- No qualifying public implementation evidence is declared and present on the canonical public tree.
