# S13: Bubble plugin

A future Bubble plugin would be a Plugin Marketplace asset added to an app in the Bubble editor, where no-code builders could review preview-mode pages and reusable elements before deploying a new version.

## Boundary

No Bubble plugin is available; a proposed implementation would inspect only preview content and properties exposed to the plugin, not change workflows, database records, privacy rules, deployment versions, or assert production compliance.

## Roles

- Bubble no-code application builder
- No-code product QA owner

## Use cases

- A builder would load a signup page in preview mode with realistic responsive conditions and review findings around controls and generated structure.
- A plugin publisher would prepare the editor element, property documentation, demo app, and version notes for Bubble Marketplace review.

## Installation

Not installable: Bubble plugin has no qualifying public implementation or package in the canonical Ariada repository.
