# S126: Balsamiq integration

Balsamiq projects contain deliberately low-fidelity wireframes that teams link into simple prototypes and circulate through review links; a future Balsamiq integration would support early accessibility decisions before visual polish obscures structural issues.

## Boundary

Ariada would treat a Balsamiq wireframe as design evidence, not a functioning interface. It would not edit the project, promise runtime semantics, mistake placeholder copy for final content, or present the integration as delivered.

## Roles

- Wireframe author
- Early-design content strategist

## Use cases

- Before a Balsamiq review link reaches stakeholders, the author would check that the proposed page hierarchy and control labels remain understandable without visual position alone.
- During a wireflow critique, the content strategist would use Ariada observations to catch ambiguous link text and missing error recovery before higher-fidelity design begins.

## Installation

Not installable: Balsamiq integration has no qualifying public implementation or package in the canonical Ariada repository.
