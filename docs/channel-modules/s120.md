# S120: Axure RP extension

Axure RP teams publish interactive prototypes to Axure Cloud for stakeholder walkthroughs and user research; a planned Axure RP extension would connect Ariada evidence to pages, widgets, and adaptive views under review.

## Boundary

Ariada would review only evidence exposed from a prototype or its rendered web output. It would not modify an RP project, understand every dynamic-panel condition, replace research with disabled participants, or claim that the extension is implemented.

## Roles

- Interaction prototyper
- UX validation researcher

## Use cases

- Before sharing an Axure Cloud prototype for usability testing, the prototyper would inspect form labels, keyboard paths, and visible focus across its primary task flow.
- During an adaptive-view critique, the researcher would compare Ariada findings for desktop and mobile prototype URLs and flag states that disappear at a breakpoint.

## Installation

Not installable: Axure RP extension has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence
