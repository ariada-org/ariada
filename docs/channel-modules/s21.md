# S21: Homebrew formula/tap

The proposed Homebrew distribution would consist of a Ruby formula in a tap, or eventually Homebrew/core, so macOS and Linux command-line users could install a released Ariada executable through `brew`.

## Boundary

No formula, tap, bottle, or core acceptance is claimed; a formula could only package an independently released executable and checksum, not create scanner functionality, host a service, or establish compliance.

## Roles

- Homebrew tap release operator
- macOS command-line accessibility tester

## Use cases

- A user would add the tap, install a pinned Ariada version, and run the CLI against a local build artifact.
- A formula contributor would update the source URL and checksum, run Homebrew audit and install checks, and submit the change for repository review.

## Installation

Not installable: Homebrew formula/tap has no qualifying public implementation or package in the canonical Ariada repository.
