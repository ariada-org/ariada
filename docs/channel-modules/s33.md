# S33: Netlify build plugin

A future Netlify Build Plugin would be an npm package configured for a site and discoverable through Netlify's integrations ecosystem, allowing Jamstack teams to inspect the publish directory during a deploy build.

## Boundary

No build plugin or Netlify listing exists; the proposed hook would analyze the generated artifact available in its build phase, not alter deploy content, read unrelated environment secrets, cancel production outside configured policy, or certify the live site.

## Roles

- Netlify site configuration owner
- Jamstack deploy evidence reviewer

## Use cases

- A site owner would add the plugin to a branch deploy, scan the publish directory, and compare its report with the deploy preview.
- An integrations reviewer would verify build-event usage, inputs, logs, package provenance, and failure semantics before making the plugin discoverable.

## Installation

Not installable: Netlify build plugin has no qualifying public implementation or package in the canonical Ariada repository.
