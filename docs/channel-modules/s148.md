# S148: Ecwid app

Ecwid merchants distribute a hosted storefront or embed catalog, product, cart, and checkout widgets into an existing site; a planned Ecwid app would help store operators review those shopper-facing surfaces with Ariada evidence.

## Boundary

Ariada would not change Ecwid catalog data, payment settings, storefront CSS, or the host site. Embedded and hosted contexts would need separate review, and the plan would not imply an Ecwid App Market release.

## Roles

- Ecwid catalog operator
- Embedded-storefront webmaster

## Use cases

- The webmaster would review an Ecwid product browser embedded in the production site's template, including keyboard movement between host navigation and store controls.
- Before enabling a new product option, the catalog operator would test its validation, cart update, and out-of-stock messages on the hosted Ecwid storefront.

## Installation

Not installable: Ecwid app has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence

- State: Planned
- Updated from evidence: Not available
- No qualifying public implementation evidence is declared and present on the canonical public tree.
