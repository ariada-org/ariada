# S75: Backstage (Spotify) plugin

A planned Backstage plugin would be an npm frontend and, if needed, backend package installed into an internal developer portal, giving platform teams a catalog-entity page for accessibility evidence associated with a service or website.

## Boundary

No Backstage package or plugin-directory entry exists; a future plugin would display or request explicitly configured evidence, not crawl every catalog entity, mutate ownership metadata, operate deployment gates, or certify services.

## Roles

- Backstage platform application engineer
- Service catalog governance owner

## Use cases

- A portal team would add an accessibility card to website entities and link each result to the owning service and source deployment.
- A platform engineer would review frontend/backend boundaries, proxy configuration, catalog permissions, package versions, and plugin-directory metadata before rollout.
