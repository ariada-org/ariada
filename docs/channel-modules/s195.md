# S195: Quasar integration

Quasar teams build Vue interfaces for SPA, SSR, PWA, Electron, or Capacitor targets from a shared component system; a planned Quasar integration would review concrete browser output while identifying the selected build mode.

## Boundary

Ariada would not infer every Quasar target from one browser build or guarantee native-wrapper behavior. The integration would leave Vue components and configuration unchanged and would not imply an installed Quasar extension.

## Roles

- Quasar frontend architect
- Multi-target release tester

## Use cases

- The architect would review dialogs, tables, drawers, and form errors in a Quasar SSR or SPA preview with the active theme and locale documented.
- The release tester would treat Electron and Capacitor packages as separate surfaces, retesting findings where native shells alter focus, zoom, or keyboard behavior.

## Installation

Not installable: Quasar integration has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence

- State: Planned
- Updated from evidence: Not available
- No qualifying public implementation evidence is declared and present on the canonical public tree.
