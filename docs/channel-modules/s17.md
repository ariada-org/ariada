# S17: Storybook addon

The source-delivered Storybook addon renders Ariada results in an addon panel for component authors and design-system reviewers examining isolated stories; npm publication is a separate distribution step.

## Boundary

The delivered source covers Storybook preview, manager, decorator, panel, and scan integration but does not prove a registry release; it evaluates the rendered story state, not every application composition or production route.

## Roles

- Storybook component author
- Design-system promotion reviewer

## Use cases

- A component author renders a menu story in its keyboard-open state and triages Ariada findings in the addon panel.
- A design-system reviewer records story-level evidence before promoting a component version for use by product teams.

## Installation

Source-delivered, not registry-published: build @ariada-org/storybook-addon with `pnpm --dir packages/ariada-storybook-addon run build`; no npm release is claimed.
