# S213: Beehiiv newsletter/landing scan recipe

Beehiiv combines newsletter posts, email delivery, a web publication, signup forms, and audience-growth features; a proposed Beehiiv newsletter/landing scan recipe would help media teams review both message and site presentations before release.

## Boundary

The recipe would not manage subscribers, send posts, change website settings, or claim control over inbox and recommendation surfaces. Dynamic and platform-owned output would need separate checks, and no Beehiiv app is implied.

## Roles

- Beehiiv publication producer
- Newsletter growth-site tester

## Use cases

- The producer would inspect a Beehiiv post in test-email and web-preview forms, checking media alternatives, semantic sections, links, and sponsor disclosures.
- The growth-site tester would complete subscribe and referral entry points on the Beehiiv site, including validation and confirmation states, before a campaign drives traffic.

## Installation

Not installable: Beehiiv newsletter/landing scan recipe has no qualifying public implementation or package in the canonical Ariada repository.
