# S163: Zapier app

Zapier apps expose triggers, actions, and searches that users connect into Zaps between SaaS products; a planned Zapier app would let automation builders start or route Ariada review events through explicit workflow steps.

## Boundary

The app would not silently crawl connected accounts, guarantee delivery beyond Zapier execution semantics, or allow a Zap to certify accessibility. It would expose no trigger or action until a real integration is separately published.

## Roles

- Zap automation builder
- SaaS operations coordinator

## Use cases

- After a CMS publishes a preview URL, a Zap would hypothetically request Ariada review and route a finding summary to the system that owns remediation.
- The operations coordinator would handle retries and duplicate events using stable review identifiers rather than creating a fresh ticket every time the Zap replays.

## Installation

Not installable: Zapier app has no qualifying public implementation or package in the canonical Ariada repository.
