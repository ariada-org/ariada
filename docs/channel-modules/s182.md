# S182: Prometheus exporter (a11y metrics)

Prometheus exporters expose numeric samples with labels at a scrape endpoint for storage, querying, and alerting; a planned Prometheus exporter (a11y metrics) would publish low-cardinality Ariada review metrics for platform operators.

## Boundary

The exporter would not place URLs, selectors, user content, or individual findings in metric labels, nor would a gauge establish compliance. It would expose no endpoint or container artifact until separately implemented.

## Roles

- Prometheus telemetry engineer
- Metric-cardinality reviewer

## Use cases

- The telemetry engineer would expose counts by product, environment, severity band, and review outcome while linking detailed evidence outside Prometheus.
- The cardinality reviewer would reject labels based on full URLs or DOM selectors and verify that repeated reviews do not create an unbounded time series.

## Installation

Not installable: Prometheus exporter (a11y metrics) has no qualifying public implementation or package in the canonical Ariada repository.
