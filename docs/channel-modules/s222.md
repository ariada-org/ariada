# S222: Confluence app (Atlassian)

Confluence apps can add macros, content actions, and space features through Atlassian distribution, while teams publish pages and templates inside spaces; a planned Confluence app would surface Ariada evidence for governed knowledge content.

## Boundary

The app would not access unapproved spaces, rewrite pages, certify Atlassian's interface, or infer attached-document accessibility from a page scan. It would not imply an Atlassian Marketplace listing.

## Roles

- Confluence space curator
- Enterprise knowledge editor

## Use cases

- Before promoting a Confluence page to an official knowledge space, the editor would review headings, links, tables, images, macros, and attachment descriptions.
- The space curator would test a shared page template with realistic macro content and assign template defects separately from author-created errors.

## Installation

Not installable: Confluence app (Atlassian) has no qualifying public implementation or package in the canonical Ariada repository.
