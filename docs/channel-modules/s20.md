# S20: WooCommerce extension

A planned WooCommerce extension would be a WordPress plugin distributed as a ZIP, through WordPress.org, or through the WooCommerce Marketplace for store operators and ecommerce developers reviewing storefront templates and commerce flows.

## Boundary

No WooCommerce extension or marketplace listing exists; a future extension would report on configured storefront and test-checkout pages without changing orders, payment settings, products, themes, or the legal accessibility status of the store.

## Roles

- WooCommerce store operator
- Commerce theme implementation developer

## Use cases

- A developer would exercise product, cart, coupon, and test-checkout states on staging and review issues introduced by a theme override.
- A store operator would inspect plugin permissions, data handling, supported WooCommerce versions, and marketplace support terms before installation.

## Installation

Not installable: WooCommerce extension has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence

- State: Planned

- No qualifying public implementation evidence is declared and present on the canonical public tree.
