# S209: HubSpot CMS app/module

HubSpot CMS distributes reusable modules and themes through the asset marketplace and Design Manager, while editors publish pages, blogs, and landing pages; a planned HubSpot CMS app/module would surface Ariada evidence in that authoring workflow.

## Boundary

The module would not alter CRM records, publish content, rewrite HubL or theme code, or certify embedded forms and scripts. It would require explicit preview targets and would not imply a HubSpot Marketplace listing.

## Roles

- HubSpot CMS developer
- Inbound content publisher

## Use cases

- Before a HubSpot landing page is scheduled, the publisher would review its preview with representative smart-content and form states rather than only the editor canvas.
- A CMS developer would test a custom HubSpot module across pages, themes, and field combinations and remediate template-level findings at their source.

## Installation

Not installable: HubSpot CMS app/module has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence

- No qualifying public implementation evidence is declared and present on the canonical public tree.
