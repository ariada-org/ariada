# S39: esbuild plugin

A proposed esbuild plugin would be distributed on npm and registered in a build configuration so fast-build users could pass emitted HTML or an explicitly served preview to Ariada after bundling.

## Boundary

No esbuild plugin package is available; a future plugin would use documented build hooks and declared outputs, not infer accessibility from JavaScript bundles alone, mutate artifacts, or claim coverage of runtime states it never renders.

## Roles

- esbuild application build owner
- Fast-build release quality engineer

## Use cases

- A build owner would register the plugin for a static application and inspect findings from emitted HTML after a successful bundle.
- A release engineer would evaluate watch-mode behavior, incremental-build cost, output-directory handling, and npm compatibility before adoption.

## Installation

Not installable: esbuild plugin has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence

- State: Planned
- Updated from evidence: Not available
- No qualifying public implementation evidence is declared and present on the canonical public tree.
