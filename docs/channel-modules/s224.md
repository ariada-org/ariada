# S224: DNN (DotNetNuke) module

DNN modules place reusable functionality on portal pages, with themes, containers, content, and permissions shaping the rendered experience; a planned DNN (DotNetNuke) module would support Ariada review by site administrators and .NET implementers.

## Boundary

The module would not edit page content, themes, module settings, users, or permissions and would not guarantee third-party extensions. It would remain a proposal without a DNN Store package claim.

## Roles

- DNN portal operator
- .NET module solution engineer

## Use cases

- A portal operator would review a DNN page with its actual containers and role-visible modules before granting broader access to the page.
- The solution engineer would test a reusable module's populated, empty, validation, and error states under supported themes before customer deployment.

## Installation

Not installable: DNN (DotNetNuke) module has no qualifying public implementation or package in the canonical Ariada repository.
