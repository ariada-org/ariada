# S219: Open edX XBlock/plugin

Open edX XBlocks render reusable learning components inside Studio-authored course units and the learner LMS; a planned XBlock/plugin would connect Ariada evidence to the unit and usage instance being reviewed.

## Boundary

The plugin would not grade learners, rewrite course OLX, certify other XBlocks, or assume Studio preview matches every deployed theme. It would remain proposed with no package or deployment claim.

## Roles

- Open edX course author
- XBlock platform developer

## Use cases

- Before publishing an Open edX unit, the author would review each XBlock in learner view, including instructions, interactive states, feedback, and completion cues.
- The platform developer would test a shared XBlock under supported themes and locales and resolve defects in its rendering rather than in every course instance.

## Installation

Not installable: Open edX XBlock/plugin has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence

- State: Planned

- No qualifying public implementation evidence is declared and present on the canonical public tree.
