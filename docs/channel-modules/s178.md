# S178: standalone Lighthouse plugin

A standalone Lighthouse plugin would be discovered as a Node package and loaded through Lighthouse configuration to contribute audits or categories to reports used by web quality teams; Ariada support is only proposed.

## Boundary

The plugin would not masquerade as a built-in Lighthouse audit, change core scores without explicit configuration, or claim full accessibility coverage. No npm artifact, plugin API compatibility, or maintained implementation would be inferred.

## Roles

- Lighthouse configuration author
- Audit-extension evaluator

## Use cases

- An evaluator would inspect a future plugin's manifest, audit definitions, and supported Lighthouse versions before allowing it in a CI image.
- The configuration author would place Ariada findings in a clearly labeled report section and preserve the distinction between Lighthouse scores and external evidence.

## Installation

Not installable: standalone Lighthouse plugin has no qualifying public implementation or package in the canonical Ariada repository.
