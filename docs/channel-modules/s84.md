# S84: Gitpod integration

The planned Gitpod integration would be a repository configuration, workspace image, or task recipe in `.gitpod.yml` that makes Ariada available to contributors when a cloud development workspace starts.

## Boundary

No Gitpod template or integration is delivered; a future configuration would provision and invoke declared tooling only, would not inspect a repository without an explicit task, access user secrets, change workspace policy, or certify the branch.

## Roles

- Gitpod workspace configuration author
- Cloud development environment administrator

## Use cases

- A repository would add an explicit task that builds a preview and runs Ariada when a contributor chooses the accessibility workflow.
- An administrator would review workspace image provenance, task timing, ports, environment variables, and prebuild cost before organization rollout.

## Installation

Not installable: Gitpod integration has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence

- State: Planned
- Updated from evidence: Not available
- No qualifying public implementation evidence is declared and present on the canonical public tree.
