# S12: Squarespace extension

The proposed Squarespace extension would target Squarespace's extension-discovery and site-owner authorization flow, giving merchants or site managers a supported route to submit public or previewable pages for review.

## Boundary

No Squarespace extension exists, and current extension APIs must be shown to expose the necessary page or preview surface before in-editor analysis can be promised; the concept would not edit blocks, publish pages, or manage commerce operations.

## Roles

- Squarespace commerce site owner
- Squarespace implementation consultant

## Use cases

- A consultant would test a product-detail and checkout-adjacent content page on a password-controlled staging site before implementation review to the owner.
- An extension publisher would validate that the requested Squarespace scopes and preview access are supported before preparing any extension-directory submission.

## Installation

Not installable: Squarespace extension has no qualifying public implementation or package in the canonical Ariada repository.
