# S134: Chromatic integration

Chromatic publishes Storybook builds, captures story snapshots, and supports component change review; a planned Chromatic integration would make Ariada evidence discoverable at the story and build level for UI library teams.

## Boundary

The integration would inspect only rendered stories included in a Chromatic build, not every application composition or hidden state. It would not approve changes, rewrite stories, certify components, or suggest a functioning Ariada connection.

## Roles

- Storybook library curator
- Component change approver

## Use cases

- On a Chromatic build for a button update, the curator would review Ariada evidence across default, disabled, loading, and icon-only stories before accepting the baseline.
- A change approver would use the story permalink and build number to return a keyboard regression to the pull request without treating unrelated snapshots as blocked.

## Installation

Not installable: Chromatic integration has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence
