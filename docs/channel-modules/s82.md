# S82: Firefox Add-ons (AMO) listing

The proposed Firefox WebExtension would be packaged as an XPI and signed or listed through addons.mozilla.org, giving Firefox users a toolbar or developer surface for analyzing an authorized active page.

## Boundary

No XPI, Mozilla signature, or AMO listing exists; a future extension would use minimal declared host permissions, would not alter page content or transmit it without disclosure, and would remain subject to Mozilla review.

## Roles

- Firefox accessibility test user
- Mozilla add-on policy reviewer

## Use cases

- A tester would grant access to a staging origin, open a dialog state in Firefox, and request a scan of the active tab.
- A publisher would submit the source and XPI with permission rationale, privacy details, data-flow documentation, and reproducible review instructions to AMO.

## Installation

Not installable: Firefox Add-ons (AMO) listing has no qualifying public implementation or package in the canonical Ariada repository.
