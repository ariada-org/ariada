# S192: NativeScript plugin

NativeScript plugins extend applications whose XML or JavaScript UI is rendered as native platform views rather than browser DOM; a planned NativeScript plugin would provide a governed implementation review for native test evidence, not a web scan disguise.

## Boundary

Ariada would not claim to inspect NativeScript's native accessibility tree without a dedicated platform harness and public evidence. The plugin would not change view properties, replace device screen-reader testing, or imply an existing package.

## Roles

- NativeScript UI developer
- Native accessibility test engineer

## Use cases

- A test engineer would associate separately collected iOS and Android accessibility evidence with a NativeScript screen and its application version for coordinated triage.
- The UI developer would verify labels, traits, focus order, and dynamic announcements on real platform views rather than treating a JavaScript component definition as rendered proof.

## Installation

Not installable: NativeScript plugin has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence

- State: Planned
- Updated from evidence: Not available
- No qualifying public implementation evidence is declared and present on the canonical public tree.
