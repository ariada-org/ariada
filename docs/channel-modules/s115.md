# S115: Nextra plugin

A future Nextra plugin would be an npm package composed with the Next.js and MDX configuration used by Nextra sites, enabling documentation developers to scan built or previewed routes.

## Boundary

No Nextra package exists; an eventual integration would require rendered targets for Next.js behavior, would not rewrite MDX or theme configuration, and would not claim coverage of authenticated or dynamic routes absent from fixtures.

## Roles

- Nextra documentation application developer
- MDX content experience reviewer

## Use cases

- A developer would build a Nextra knowledge base, render a representative search and navigation state, and review findings before Vercel deployment.
- An experience reviewer would assess Nextra and Next.js compatibility, config composition, route fixtures, package provenance, and build overhead before adoption.

## Installation

Not installable: Nextra plugin has no qualifying public implementation or package in the canonical Ariada repository.
