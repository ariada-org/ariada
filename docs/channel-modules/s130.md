# S130: TestCafe plugin

TestCafe organizes automated browser journeys as fixtures and tests with selector-based actions and run reports; a planned TestCafe plugin would provide Ariada evidence to teams still reviewing releases through that runner.

## Boundary

The plugin would cover only pages and states explicitly exercised by TestCafe. It would not modernize or replace the test framework, inspect native UI outside the browser, fix source markup, or represent a released Ariada artifact.

## Roles

- TestCafe suite owner
- Legacy web QA lead

## Use cases

- Within a TestCafe purchase fixture, the suite owner would request Ariada evidence after validation messages appear so hidden and visible error text can be reviewed together.
- The QA lead would compare a baseline report with a release-candidate run and route only newly introduced findings to the checkout team.

## Installation

Not installable: TestCafe plugin has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence
