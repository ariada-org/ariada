# S46: Parcel transformer/reporter

A planned Parcel package would be configured in `.parcelrc` as a reporter or another justified plugin type, allowing application teams to evaluate built HTML when Parcel completes a development or production bundle.

## Boundary

No Parcel package is available; the design must use the plugin role that matches Parcel's API and must not disguise analysis as an asset transformation, rewrite bundles, or claim visibility into runtime states absent from the output.

## Roles

- Parcel configuration engineer
- Zero-config application release lead

## Use cases

- A Parcel project would register the reporter, build its site, and retain findings linked to the resulting bundle graph and HTML assets.
- A configuration engineer would assess `.parcelrc` composition, cache behavior, watch rebuilds, diagnostic output, and supported Parcel versions before adoption.

## Installation

Not installable: Parcel transformer/reporter has no qualifying public implementation or package in the canonical Ariada repository.
