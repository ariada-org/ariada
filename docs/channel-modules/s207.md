# S207: Mailchimp landing/campaign scan recipe

Mailchimp users compose email campaigns, templates, signup forms, and hosted landing pages for an audience; a planned Mailchimp landing/campaign scan recipe would guide campaign producers through reviewing the actual web and email outputs.

## Boundary

The recipe would not access audiences, send campaigns, edit templates, or guarantee rendering in every inbox. Ariada web checks would not be misrepresented as complete email-client or screen-reader coverage, and no automated connector is implied.

## Roles

- Mailchimp campaign producer
- Audience experience reviewer

## Use cases

- Before scheduling a Mailchimp campaign, the producer would inspect exported email HTML and test messages for headings, link purpose, image alternatives, and usable fallback content.
- The reviewer would scan the hosted Mailchimp landing page and signup confirmation flow separately because their web behavior differs from the delivered email.

## Installation

Not installable: Mailchimp landing/campaign scan recipe has no qualifying public implementation or package in the canonical Ariada repository.
