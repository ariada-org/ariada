# S42: SWC plugin/wrapper

The proposed SWC offering would be a supported transform plugin or command wrapper distributed through the appropriate JavaScript or Rust package channel, used by compiler teams to inspect source syntax or explicitly rendered output.

## Boundary

No SWC plugin or wrapper is implemented, and no universal SWC hook for rendered-page analysis is assumed; source transforms cannot see the final DOM, so any future capability would declare whether it analyzes AST input, build output, or a separate browser target.

## Roles

- SWC compiler integration engineer
- Monorepo transpilation policy owner

## Use cases

- A compiler engineer would evaluate a non-mutating JSX analysis pass and map findings back through source locations during a test build.
- A policy owner would compare native-plugin and wrapper deployment constraints, supported SWC versions, package provenance, and failure behavior before choosing a distribution form.

## Installation

Not installable: SWC plugin/wrapper has no qualifying public implementation or package in the canonical Ariada repository.
