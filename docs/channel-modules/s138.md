# S138: Plasmic plugin

Plasmic projects contain reusable components, page designs, variants, and published or code-integrated output; a proposed Plasmic plugin would support Ariada review by visual builders and engineers at the preview boundary.

## Boundary

The plugin would not assume Plasmic Studio and every consuming application render identically. It would leave projects and generated code unchanged, avoid publishing actions, and remain a proposed review path rather than a shipped plugin.

## Roles

- Plasmic page builder
- Code-component integrator

## Use cases

- Before a Plasmic page is published, the page builder would review responsive variants and resolve content-order findings in the relevant frame.
- A component integrator would expose disabled, invalid, and expanded states for a registered code component so Ariada evidence reflects more than its default canvas rendering.

## Installation

Not installable: Plasmic plugin has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence

- State: Planned

- No qualifying public implementation evidence is declared and present on the canonical public tree.
