# S30: Chrome DevTools panel

The planned DevTools panel would be part of a Chrome extension distributed through the Chrome Web Store, giving frontend debuggers a dedicated surface for analyzing the DOM and state of the currently inspected tab.

## Boundary

No Chrome extension or Web Store item is available; a future panel would be confined to tabs and host permissions granted by the user, would not edit the originating application, and would remain subject to Chrome extension review and policy.

## Roles

- Chrome-based frontend debugger
- Browser-extension security assessor

## Use cases

- A developer would open DevTools on a modal in its active state and run the panel against the inspected page before committing a fix.
- A security assessor would review host permissions, content-script isolation, data transmission, and store disclosures before publication.

## Installation

Not installable: Chrome DevTools panel has no qualifying public implementation or package in the canonical Ariada repository.
