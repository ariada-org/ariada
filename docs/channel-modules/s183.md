# S183: OpenTelemetry instrumentation

OpenTelemetry carries vendor-neutral traces, metrics, logs, resources, and attributes through SDKs and collectors; proposed Ariada instrumentation would correlate review activity with deployment telemetry for observability platform teams.

## Boundary

Instrumentation would not capture page bodies, credentials, or selectors by default and would not redefine OpenTelemetry semantic conventions without governance. It would report process telemetry, not certify content, and remains planned.

## Roles

- Telemetry schema governor
- Collector pipeline operator

## Use cases

- A schema governor would define bounded attributes for review ID, deployment, outcome, and duration while keeping sensitive evidence at its source.
- The collector operator would route proposed Ariada spans and metrics to approved backends and diagnose dropped exports without confusing telemetry loss with a passed review.

## Installation

Not installable: OpenTelemetry instrumentation has no qualifying public implementation or package in the canonical Ariada repository.
