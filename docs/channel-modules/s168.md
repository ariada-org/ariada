# S168: AWS Lambda layer / CodeBuild step

AWS Lambda layers distribute shared runtime dependencies, while CodeBuild executes declared build phases and preserves logs and artifacts; a proposed AWS Lambda layer / CodeBuild step would place Ariada review in an explicitly configured build job.

## Boundary

A layer would not make arbitrary Lambda functions accessibility-aware, and a build step would inspect only reachable web output. The plan would not modify AWS resources, bundle undisclosed code, or claim a published layer or image.

## Roles

- CodeBuild pipeline engineer
- AWS runtime security reviewer

## Use cases

- After CodeBuild starts an ephemeral documentation site, the pipeline engineer would run a proposed Ariada step against named routes and retain evidence with the build artifacts.
- The security reviewer would constrain network access and pin any future layer or build image before approving it for workloads that handle internal preview URLs.

## Installation

Not installable: AWS Lambda layer / CodeBuild step has no qualifying public implementation or package in the canonical Ariada repository.
