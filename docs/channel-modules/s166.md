# S166: Notion integration

Notion integrations use scoped API access to read or write shared pages, databases, and blocks for workspace users; a proposed Notion integration would publish governed Ariada review summaries into selected planning or content records.

## Boundary

The integration would not gain access to pages that were not shared with it, treat Notion blocks as the rendered product, or rewrite source content. It would not imply a public integration or available OAuth flow.

## Roles

- Notion workspace integrator
- Editorial governance lead

## Use cases

- An editorial database entry would receive a proposed Ariada summary for its published URL, allowing the governance lead to assign findings before changing the publication status.
- The workspace integrator would store links and stable identifiers rather than copying sensitive page evidence into broadly shared Notion properties.

## Installation

Not installable: Notion integration has no qualifying public implementation or package in the canonical Ariada repository.
