# S76: GitHub Codespaces / devcontainer Feature

The proposed devcontainer Feature would be a versioned OCI artifact referenced from `devcontainer.json`, allowing Codespaces and compatible development-container users to provision Ariada tooling with a workspace.

## Boundary

No Feature artifact or registry release exists; a future Feature would install a declared tool version only, would not scan repositories automatically, obtain secrets, change Codespaces policy, or imply that the provisioned workspace passed review.

## Roles

- Development-container image author
- Codespaces repository onboarding lead

## Use cases

- A repository would pin the Feature in its devcontainer and expose an explicit scan task for contributors opening a Codespace.
- A Feature publisher would test supported base images, architectures, install options, OCI labels, and release tags before registry publication.

## Installation

Not installable: GitHub Codespaces / devcontainer Feature has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence

- State: Planned
- Updated from evidence: Not available
- No qualifying public implementation evidence is declared and present on the canonical public tree.
