# S158: Linear integration

Linear integrations connect external work to issues, projects, cycles, labels, and comments used by product engineering teams; a proposed Linear integration would make Ariada evidence actionable without presenting issue tracking as the scan itself.

## Boundary

The connection would not inspect products through Linear, assign findings without configured ownership, or override priority and completion decisions. It would use authorized workspace access only and would not imply an available integration.

## Roles

- Linear triage lead
- Product engineering planner

## Use cases

- A triage lead would convert a confirmed Ariada regression into a Linear issue linked to the active project and include route, state, and evidence needed to reproduce it.
- During cycle planning, the planner would group related findings by product area and keep deferred risk visible without manufacturing duplicate issues for every scan.

## Installation

Not installable: Linear integration has no qualifying public implementation or package in the canonical Ariada repository.
