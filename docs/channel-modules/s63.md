# S63: Umbraco package (.NET)

A future Umbraco package would be delivered through NuGet and discoverable in the Umbraco Marketplace, adding a backoffice surface for editors and .NET solution teams to assess rendered content previews.

## Boundary

No NuGet package or Umbraco listing exists; a future package would operate within backoffice permissions and configured preview routes, without changing content, publishing variants, modifying templates, or certifying the site.
