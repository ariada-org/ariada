# S2: Package the VS Code extension for publish

The source-delivered VS Code extension provides editor diagnostics and scan commands for developers working in supported web-template files; its distributable object is a VSIX, while Marketplace publication remains separate work.

## Boundary

The current manifest is private and supports controlled VSIX evaluation rather than a Visual Studio Marketplace or Open VSX listing; diagnostics are advisory, and untrusted workspaces remain read-only.

## Roles

- VS Code extension release publisher
- Component-template accessibility engineer

## Use cases

- A frontend engineer opens an HTML, JSX, TSX, Vue, Svelte, or Angular template and reviews Ariada diagnostics beside the affected source.
- An extension publisher packages the private VSIX, installs it in a clean VS Code profile, and assesses commands and trust behavior before any store submission.

## Installation

Source-delivered, not marketplace-published: run `pnpm --dir packages/vscode-extension run package` to build the private @ariada-org/vscode-extension VSIX from its public manifest.
