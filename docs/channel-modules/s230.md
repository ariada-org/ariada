# S230: Lerna task

Lerna runs scripts across selected workspace packages and coordinates package versioning and publishing in JavaScript monorepos; a proposed Lerna task would invoke Ariada only for packages that produce a reviewable web application or documentation site.

## Boundary

The task would not replace Lerna commands, version packages, publish releases, or pretend source-only libraries can be accessibility-scanned. No task package, lifecycle hook, or working integration would be implied.

## Roles

- Lerna workspace operator
- Package-release train coordinator

## Use cases

- The workspace operator would use Lerna filtering to run a proposed Ariada script for changed demo and documentation packages after their previews start.
- The release coordinator would keep accessibility evidence separate from version calculation and decide explicitly whether a finding blocks the corresponding package release.

## Installation

Not installable: Lerna task has no qualifying public implementation or package in the canonical Ariada repository.
