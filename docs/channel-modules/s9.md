# S9: Joomla plugin

A future Joomla extension package and Joomla Extensions Directory entry would let site administrators and template developers review rendered articles, modules, and template overrides before they are exposed on the public site.

## Boundary

No Joomla install package or directory listing is present; the proposed plugin would report on pages it can render or fetch, without modifying articles, changing menu assignments, publishing modules, or replacing human conformance review.

## Roles

- Joomla site administrator
- Template-override developer

## Use cases

- A template developer would render an article with its assigned modules and inspect issues introduced by an override before deploying the template update.
- A site administrator would review the extension's Joomla version range, update server, permissions, and JED disclosure before a staging installation.
