# S4: JetBrains plugin (new build)

The source-delivered JetBrains plugin contributes an IDE action and Ariada tool window for developers reviewing the current project file; a signed plugin archive and Marketplace entry would be its distribution surfaces.

## Boundary

Source delivery supports local archive evaluation but does not establish a JetBrains Marketplace listing; the plugin reports deterministic findings for the selected file and does not rewrite project code or attest to the whole application.

## Roles

- JetBrains IDE plugin evaluator
- JVM web-interface developer

## Use cases

- A developer invokes Scan with Ariada on the active template and triages results in the dedicated IDE tool window.
- An IDE administrator installs a locally built archive into a test IDE and checks compatibility, permissions, and presentation before considering Marketplace rollout.

## Installation

Source-delivered, not marketplace-published: run `packages/ariada-jetbrains-plugin/gradlew -p packages/ariada-jetbrains-plugin buildPlugin` for plugin id org.ariada.jetbrains.
