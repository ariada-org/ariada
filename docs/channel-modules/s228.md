# S228: Turborepo integration

Turborepo coordinates package scripts across workspaces using dependency-aware tasks, filters, and local or remote caching; a future integration would place Ariada review after the specific web application's build and preview tasks.

## Boundary

The integration would not change Turborepo's task graph, publish workspaces, or treat cache success as accessibility evidence. It would require explicit scripts and targets and would not imply a package or native Turborepo feature.

## Roles

- Turborepo pipeline designer
- Workspace cache reliability owner

## Use cases

- The pipeline designer would make a proposed Ariada task depend on the selected app's build and preview readiness rather than running against source packages with no rendered surface.
- The cache owner would include deployment identity and review configuration in task inputs so remote cache hits cannot return evidence from another preview.

## Installation

Not installable: Turborepo integration has no qualifying public implementation or package in the canonical Ariada repository.
