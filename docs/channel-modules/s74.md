# S74: Read the Docs build integration

The proposed Read the Docs integration would be a project configuration recipe or supported build command that analyzes generated documentation HTML inside the hosted build used by documentation authors and project administrators.

## Boundary

No Read the Docs plugin or endorsed integration exists; any future recipe would operate within documented build-job and sandbox limits, would not change source or publish versions, and would leave build status and hosting policy to Read the Docs.

## Roles

- Read the Docs project administrator
- Hosted documentation build author

## Use cases

- A project administrator would add a post-build analysis command for the generated HTML and expose the report in build logs or retained artifacts where supported.
- A documentation author would inspect findings from a pull-request build before merging content that Read the Docs will publish.

## Installation

Not installable: Read the Docs build integration has no qualifying public implementation or package in the canonical Ariada repository.
