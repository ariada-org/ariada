# S116: Pelican plugin

The planned Pelican plugin would be a Python package enabled in Pelican settings and attached to generation signals so blog and documentation publishers could inspect the generated output directory.

## Boundary

No Pelican plugin or PyPI release exists; a future plugin would read generated HTML without changing source articles, Jinja themes, metadata, or publication destinations, and would not cover scripts and embeds absent from the build.

## Roles

- Pelican static-site developer
- Python-based editorial publisher

## Use cases

- A developer would generate articles, categories, tags, and archives with a custom theme and scan the output before syncing it to hosting.
- A publisher would evaluate Pelican signals, settings schema, theme and Python compatibility, package ownership, and PyPI release information before installation.

## Installation

Not installable: Pelican plugin has no qualifying public implementation or package in the canonical Ariada repository.
