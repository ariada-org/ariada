# S211: Kit (ex-ConvertKit) landing/newsletter scan recipe

Kit creators publish broadcasts, automated sequences, forms, and landing pages to grow and serve subscriber audiences; a proposed Kit (ex-ConvertKit) landing/newsletter scan recipe would guide creators through reviewing each delivery surface before publication.

## Boundary

The recipe would not access subscribers, send broadcasts, change sequences, or guarantee inbox rendering. Ariada would assess supplied web or HTML evidence only, and the recipe would not imply an installed Kit app.

## Roles

- Kit newsletter creator
- Creator-audience accessibility editor

## Use cases

- Before sending a Kit broadcast, the creator would review a test message for meaningful link text, image alternatives, heading structure, and reliance on color.
- The editor would complete the hosted Kit form and landing-page flow with a keyboard, checking errors and confirmation messaging separately from the newsletter template.

## Installation

Not installable: Kit (ex-ConvertKit) landing/newsletter scan recipe has no qualifying public implementation or package in the canonical Ariada repository.
