# S181: Grafana plugin / datasource

Grafana plugins and data sources make external time-series or records queryable in panels and dashboards used by operations teams; a proposed Grafana plugin / datasource would visualize Ariada review trends without replacing source evidence.

## Boundary

The plugin would not claim Grafana itself scanned pages, expose raw sensitive findings to every dashboard viewer, or make panel thresholds compliance decisions. No signed plugin or catalog publication would be implied.

## Roles

- Grafana dashboard designer
- Accessibility program analyst

## Use cases

- A program analyst would filter a Grafana panel by product, release, and finding class, then open the governed Ariada record for remediation details.
- The dashboard designer would distinguish unreviewed targets, scan failures, and confirmed regressions so a missing data point is not displayed as zero defects.

## Installation

Not installable: Grafana plugin / datasource has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence

- State: Planned
- Updated from evidence: Not available
- No qualifying public implementation evidence is declared and present on the canonical public tree.
