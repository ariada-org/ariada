# S95: Flask extension

The proposed Flask extension would be a PyPI package initialized with an application and surfaced through a CLI command or test helper, serving small web-service teams that render Jinja pages.

## Boundary

No Flask extension exists; a future implementation would analyze responses or URLs explicitly produced by the application, would not treat API JSON as a visual interface, change request handling, or provide browser interaction unless separately configured.

## Roles

- Flask application developer
- Jinja interface test lead

## Use cases

- A developer would create the Flask test app with fixtures, request a rendered account page, and pass its HTML to the extension for analysis.
- A test lead would assess application-factory support, CLI behavior, context handling, Flask versions, and PyPI provenance before team use.

## Installation

Not installable: Flask extension has no qualifying public implementation or package in the canonical Ariada repository.
