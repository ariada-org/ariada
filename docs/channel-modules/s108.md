# S108: Jekyll plugin

A future Jekyll plugin would be a RubyGem enabled in `_config.yml` and connected to Jekyll build hooks so theme and documentation teams could inspect generated `_site` HTML.

## Boundary

No Jekyll gem is published; custom plugins are not executed by GitHub Pages safe mode, so hosted users would need a separate build workflow, and the plugin would not rewrite posts, themes, or published pages.

## Roles

- Jekyll theme developer
- GitHub Pages documentation owner

## Use cases

- A theme developer would add the gem to a custom build, generate `_site`, and review findings for posts, archives, and navigation before deployment.
- A GitHub Pages owner would decide between an external Actions build and supported safe-mode behavior after reviewing gem dependencies and Jekyll compatibility.

## Installation

Not installable: Jekyll plugin has no qualifying public implementation or package in the canonical Ariada repository.
