# S203: ExpressionEngine add-on

ExpressionEngine publishes channel entries through templates and add-ons configured in its control panel; a proposed ExpressionEngine add-on would surface Ariada review evidence for channel editors and template developers before site publication.

## Boundary

The add-on would not edit channel data, template groups, member permissions, or third-party add-on output, and would not promise automatic remediation. It would not imply a listing or downloadable add-on.

## Roles

- ExpressionEngine channel editor
- EE template-group developer

## Use cases

- Before releasing a new ExpressionEngine template group, the developer would review entries containing long titles, missing media, pagination, and validation errors.
- A channel editor would use public-page evidence to fix entry-level content while escalating structural findings tied to shared template tags.

## Installation

Not installable: ExpressionEngine add-on has no qualifying public implementation or package in the canonical Ariada repository.

- No qualifying public implementation evidence is declared and present on the canonical public tree.
