# S79: Discord bot

A proposed Discord application would be installed to a server through OAuth and use bot commands or channel messages to deliver scan summaries for open-source communities and release coordinators.

## Boundary

No Discord application, bot token, or App Directory listing exists; a future bot would handle only explicit commands and supplied reports, not inspect private conversations, moderate members, operate CI, or make compliance decisions.

## Roles

- Discord community server administrator
- Open-source release coordination lead

## Use cases

- A release workflow would post a concise failed-scan summary and artifact link into a designated project channel.
- A server administrator would authorize the bot with minimal channel permissions and test command visibility, retention, and error handling before wider use.

## Installation

Not installable: Discord bot has no qualifying public implementation or package in the canonical Ariada repository.
