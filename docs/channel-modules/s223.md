# S223: Liferay portlet

Liferay widgets and portlets render content and application functions on site pages managed through display pages, fragments, and permissions; a proposed Liferay portlet would present Ariada evidence to portal administrators and content teams.

## Boundary

The portlet would not change Liferay pages, fragments, users, roles, or workflow states and would not certify every deployed widget. It would review authorized rendered pages only and would not imply Marketplace distribution.

## Roles

- Liferay portal administrator
- Digital workplace page designer

## Use cases

- Before publishing a Liferay display page, the designer would review assembled fragments and widgets with the permissions and locale of the intended audience.
- The portal administrator would evaluate a shared theme or navigation update across representative sites and route common defects to platform engineering.

## Installation

Not installable: Liferay portlet has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence

- State: Planned
- Updated from evidence: Not available
- No qualifying public implementation evidence is declared and present on the canonical public tree.
