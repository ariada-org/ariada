# S8: TYPO3 extension

The planned TYPO3 extension would be packaged for Composer and the TYPO3 Extension Repository, allowing integrators and backend editors to assess page previews produced by TypoScript, Fluid templates, and content elements.

## Boundary

No TER or Composer artifact exists; a future extension would read configured rendered previews and return evidence, while TYPO3 continues to control workspaces, permissions, localization, publication, and template changes.

## Roles

- TYPO3 integrator
- Backend page-quality editor

## Use cases

- A backend editor would preview a localized workspace version of a page and examine accessibility findings before publishing the workspace change.
- An integrator would inspect extension metadata, supported TYPO3 versions, backend permissions, and Composer dependencies before approving installation.

## Installation

Not installable: TYPO3 extension has no qualifying public implementation or package in the canonical Ariada repository.
