# S160: Trello Power-Up

Trello Power-Ups add card buttons, badges, board views, and external links to lightweight visual workflows; a prospective Trello Power-Up would summarize Ariada evidence on the card representing a page or release.

## Boundary

The Power-Up would not scan arbitrary boards, change card membership or due dates, decide when a finding is accepted, or imply listing in the Power-Up directory. Detailed evidence would remain at its governed source.

## Roles

- Trello board steward
- Small-team release coordinator

## Use cases

- A release card would display a proposed Ariada badge count and link reviewers to findings for the exact preview URL rather than copying sensitive evidence into Trello.
- Before moving a card to Published, the coordinator would confirm that blocking findings have named owners and documented dispositions, not merely a cleared checklist.

## Installation

Not installable: Trello Power-Up has no qualifying public implementation or package in the canonical Ariada repository.
