# S196: PWA manifest + service-worker a11y audit

A PWA manifest describes install metadata and a service worker controls fetch and caching behavior, while users interact with the linked web application's pages; a proposed audit would combine Ariada page review with limited install-surface checks.

## Boundary

Neither a valid manifest nor a working service worker proves accessibility. Ariada would not certify offline flows without exercising them, rewrite caching logic, or claim that metadata inspection covers browser and installed-app behavior.

## Roles

- PWA application engineer
- Offline-experience test analyst

## Use cases

- The engineer would review manifest names, icons, orientation assumptions, and the rendered install landing page while keeping metadata checks separate from DOM findings.
- The analyst would exercise an offline route with the service worker active and examine whether cached errors, reconnect notices, and navigation remain perceivable and operable.

## Installation

Not installable: PWA manifest + service-worker a11y audit has no qualifying public implementation or package in the canonical Ariada repository.
