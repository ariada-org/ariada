# S15: ESLint plugin

A proposed ESLint plugin would be an npm-distributed rule package configured by JavaScript teams in flat or legacy ESLint configuration to flag accessibility-relevant patterns in JSX and other supported syntax during linting.

## Boundary

No ESLint package or ruleset is published; any future rules would be limited to syntax and semantic information available in the lint AST, not computed styles, browser state, rendered DOM behavior, automatic fixes without safe semantics, or compliance certification.

## Roles

- JavaScript lint-policy owner
- Frontend component author

## Use cases

- A component team would enable selected rules in its shared flat config and review a pull-request annotation for an unlabeled interactive element.
- A lint-policy owner would evaluate rule schemas, recommended presets, parser compatibility, and false-positive guidance before adopting a registry release.

## Installation

Not installable: ESLint plugin has no qualifying public implementation or package in the canonical Ariada repository.
