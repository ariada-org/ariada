# S128: Playwright reporter/fixture

Playwright fixtures prepare browser state while reporters summarize tests, attachments, traces, and projects; a proposed Playwright reporter/fixture would expose Ariada findings in the artifacts reviewed by cross-browser automation teams.

## Boundary

The adapter would run only where a suite invokes it and would see only rendered states the tests reach. It would not make Playwright traces exhaustive, replace manual assistive-technology testing, change the application, or claim present implementation.

## Roles

- Playwright framework engineer
- Cross-browser quality analyst

## Use cases

- A fixture would hypothetically prepare an authenticated dashboard, then the reporter would preserve Ariada evidence beside the corresponding Playwright test result for triage.
- The quality analyst would compare Chromium, Firefox, and WebKit project findings for a release candidate and investigate browser-specific focus or name differences.

## Installation

Not installable: Playwright reporter/fixture has no qualifying public implementation or package in the canonical Ariada repository.
