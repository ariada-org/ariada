# S236: Histoire / Ladle addon (Storybook-alternatives)

Histoire and Ladle publish component stories as fast local or static preview sites that teams browse by story and variant outside Storybook; a proposed addon would attach Ariada evidence to those rendered story objects.

## Boundary

The addon would support only documented Histoire or Ladle surfaces rather than treating both tools as identical. It would not rewrite stories, approve components, publish static sites, or imply an available addon package.

## Roles

- Alternative-story explorer owner
- Component variant acceptance tester

## Use cases

- The tester would review interactive, error, loading, and responsive variants in a Histoire story before its static preview is shared with consumers.
- For a Ladle build, the explorer owner would link findings to the exact story and component revision while reserving application composition for downstream testing.

## Installation

Not installable: Histoire / Ladle addon (Storybook-alternatives) has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence
