# S200: Grav (flat-file) plugin

Grav builds sites from Markdown pages, YAML frontmatter, themes, and plugins stored in a flat-file hierarchy, with optional Admin editing; a proposed Grav plugin would review generated routes for publishers and theme authors.

## Boundary

The plugin would not edit Markdown, frontmatter, Twig templates, or filesystem permissions, and would not assume every Grav theme behaves alike. It would not imply availability through Grav's package manager.

## Roles

- Grav theme author
- Flat-file publication editor

## Use cases

- The theme author would review representative Grav page types after changing Twig layout or navigation, including taxonomy listings and modular pages.
- Before publishing Markdown content, the editor would inspect generated headings, link text, tables, and image alternatives rather than relying on source syntax alone.

## Installation

Not installable: Grav (flat-file) plugin has no qualifying public implementation or package in the canonical Ariada repository.
