# S41: Rollup plugin

A future Rollup plugin would be an npm-distributed plugin using output-generation hooks to hand relevant HTML artifacts or preview targets to Ariada for site and library demo teams.

## Boundary

No Rollup plugin exists; because many Rollup builds emit libraries rather than pages, a future integration would require explicit scannable inputs, avoid changing bundles, and make no claim about UI that was not rendered.

## Roles

- Rollup build pipeline author
- Library demo-site release reviewer

## Use cases

- A demo-site build would scan the generated example HTML during `generateBundle` or a subsequent close step and store its report with the release candidate.
- A pipeline author would verify output-format behavior, multi-output handling, watch rebuilds, and npm peer ranges before enabling the plugin.

## Installation

Not installable: Rollup plugin has no qualifying public implementation or package in the canonical Ariada repository.
