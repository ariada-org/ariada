# S216: Litmus email-HTML a11y integration

Litmus lets email teams build or upload HTML, generate previews across clients, run pre-send checks, and collaborate on proofing; a planned Litmus email-HTML a11y integration would add Ariada evidence to the message version under review.

## Boundary

Ariada would not replace Litmus client previews, send tests, or prove behavior in every inbox and screen-reader combination. It would not alter email HTML or imply a Litmus Marketplace integration exists.

## Roles

- Litmus proofing specialist
- Email design-system engineer

## Use cases

- The proofing specialist would pair Ariada HTML findings with Litmus previews for the same message version, checking whether client transformations change reading or visual order.
- The design-system engineer would review shared email modules before release and then verify assembled campaigns because template correctness does not cover editorial content.

## Installation

Not installable: Litmus email-HTML a11y integration has no qualifying public implementation or package in the canonical Ariada repository.
