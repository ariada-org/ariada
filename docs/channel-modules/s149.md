# S149: Shopware plugin

Shopware extensions are installed into stores and can affect Administration workflows, storefront themes, products, and checkout; a prospective Shopware plugin would expose Ariada findings to merchants and implementation partners for chosen sales-channel pages.

## Boundary

The plugin would not write Shopware entities, modify Twig or storefront code, place orders, or grant compliance. It would be separate from the Shopware Store review process and would remain unavailable until independently delivered.

## Roles

- Shopware merchant administrator
- Storefront implementation partner

## Use cases

- Before activating a Shopware theme update on a sales channel, the partner would review listing, detail, off-canvas cart, and checkout states against Ariada evidence.
- A merchant administrator would trace inaccessible promotional content to a Shopping Experiences block and return a precise correction to the page editor.

## Installation

Not installable: Shopware plugin has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence
