# S102: .NET global tool + MSBuild task

The proposed .NET distribution would use NuGet for a local or global tool and an MSBuild task package, enabling ASP.NET teams to analyze published static output or explicitly hosted test routes.

## Boundary

No NuGet tool or task package is available; a future integration would not infer accessibility from assemblies, Razor source, XAML, or native UI, would require rendered web inputs, and would not alter project files without explicit setup.

## Roles

- ASP.NET web application engineer
- MSBuild platform task owner

## Use cases

- A repository would pin the tool in a local manifest and run it against browser assets produced by `dotnet publish` or a test server.
- An MSBuild owner would evaluate target ordering, incremental inputs and outputs, target frameworks, package signatures, and NuGet metadata before importing the task.

## Installation

Not installable: .NET global tool + MSBuild task has no qualifying public implementation or package in the canonical Ariada repository.
