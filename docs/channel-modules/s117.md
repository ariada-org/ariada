# S117: Adobe XD plugin

A proposed Adobe XD plugin would be a plugin bundle loaded through XD's plugin management and, where current Adobe distribution policy permits, a discoverable marketplace item for designers reviewing artboards, components, and prototype states.

## Boundary

No XD plugin or marketplace availability is claimed; any future work would first confirm Adobe's current XD and plugin-distribution support, would inspect only exposed design objects, and would not edit prototypes or certify the implemented product.

## Roles

- Adobe XD product interface designer
- Legacy design-system accessibility auditor

## Use cases

- A designer would select linked artboards and component states for a checkout prototype and review design-level findings before developer implementation review.
- A plugin publisher would verify current XD support, bundle signing, permissions, review eligibility, and update distribution before promising availability.

## Installation

Not installable: Adobe XD plugin has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence

- State: Planned

- No qualifying public implementation evidence is declared and present on the canonical public tree.
