# S201: Kirby (flat-file) plugin

Kirby sites render file-based content through PHP templates, snippets, blueprints, and custom Panel fields; a future Kirby plugin would provide Ariada evidence to developers and editors reviewing the resulting public pages.

## Boundary

The plugin would not alter content files, blueprints, templates, licenses, or Panel permissions and could not guarantee custom blocks it has not rendered. No Composer package or Kirby plugin listing would be claimed.

## Roles

- Kirby template developer
- Panel content curator

## Use cases

- A template developer would review each Kirby template with representative blocks and multilingual content before deploying a shared snippet change.
- The Panel curator would use Ariada evidence from the public page to revise editorial fields while leaving structural template defects with engineering.

## Installation

Not installable: Kirby (flat-file) plugin has no qualifying public implementation or package in the canonical Ariada repository.

- No qualifying public implementation evidence is declared and present on the canonical public tree.
