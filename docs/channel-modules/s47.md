# S47: Next.js plugin / integration

The proposed Next.js integration would be an npm package and configuration layer used by framework teams to scan rendered route fixtures or deployment previews across Pages or App Router applications.

## Boundary

No Next.js package is delivered; a future integration could not derive complete accessibility from `.next` bundles alone and would need explicit URLs, data fixtures, and authentication for dynamic states, without modifying routes or approving deployment.

## Roles

- Next.js application platform developer
- Server-rendered route QA lead

## Use cases

- A team would start the production preview, visit representative server and static routes with test data, and collect findings before promotion.
- A platform developer would evaluate supported Next.js versions, routing modes, middleware interaction, and package configuration before enabling the integration.

## Installation

Not installable: Next.js plugin / integration has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence

- State: Planned
- Updated from evidence: Not available
- No qualifying public implementation evidence is declared and present on the canonical public tree.
