# S87: pytest plugin

The planned pytest plugin would be a PyPI package discovered through pytest entry points, providing fixtures, markers, or options for Python web test suites to pass rendered HTML or authorized URLs to Ariada.

## Boundary

No pytest package is published; a future plugin would not provide browser automation unless explicitly integrated with one, would not treat JSON responses as user interfaces, and would leave fixture setup, authentication, assertions, and failure policy to the suite.

## Roles

- Python web test automation engineer
- pytest suite architecture owner

## Use cases

- A test would render a Django response with known fixture data, submit its HTML through the plugin, and assert the team's chosen threshold.
- A suite owner would evaluate plugin discovery, marker registration, report sections, xdist behavior, and PyPI compatibility before enabling it.

## Installation

Not installable: pytest plugin has no qualifying public implementation or package in the canonical Ariada repository.

- No qualifying public implementation evidence is declared and present on the canonical public tree.
