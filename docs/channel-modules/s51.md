# S51: Remix / React-Router integration

The proposed integration would be a package for Remix or React Router framework-mode applications, used by full-stack teams to exercise rendered routes with representative loader data during preview or test runs.

## Boundary

No Remix or React Router integration is available; a future package would declare the framework versions and execution mode it supports, require fixtures for data and authentication, and avoid claiming that route modules alone represent rendered accessibility.

## Roles

- React Router framework developer
- Full-stack route release reviewer

## Use cases

- A developer would launch a production preview, load a form route with validation errors, and inspect findings for that rendered state.
- A release reviewer would check compatibility with the project's routing mode, server adapter, data loaders, and package version before adding it to CI.

## Installation

Not installable: Remix / React-Router integration has no qualifying public implementation or package in the canonical Ariada repository.
