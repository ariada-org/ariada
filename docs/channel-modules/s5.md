# S5: Figma plugin (new build)

A planned Figma plugin would be distributed by manifest during development and, after Figma review, through the Figma Community so product designers and design-system teams could examine selected frames, components, and layer metadata inside a design file.

## Boundary

No Figma plugin or Community listing is available; a future plugin could analyze only objects exposed by Figma's plugin API and would not silently edit the file, publish a library, validate coded UI, or turn design evidence into compliance certification.

## Roles

- Figma product designer
- Design-system library accessibility reviewer

## Use cases

- A design-system reviewer would select component variants and compare reported naming, contrast, and structural concerns before publishing a library update.
- A plugin publisher would test the manifest, permissions, onboarding, and Community metadata in a development file before submitting the plugin for Figma's review.

## Installation

Not installable: Figma plugin (new build) has no qualifying public implementation or package in the canonical Ariada repository.
