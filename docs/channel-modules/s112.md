# S112: Zola integration

A planned Zola integration would be an external CLI or reusable CI recipe run after `zola build`, giving Rust-oriented static-site authors a concrete way to analyze the generated `public` directory.

## Boundary

No Zola integration is delivered, and Zola has no general runtime plugin system that should be implied; a future workflow would remain an external build step, would not alter templates or content, and would not publish the site.

## Roles

- Zola static-site author
- Rust-based documentation pipeline engineer

## Use cases

- An author would build a multilingual Zola site and run the external scan across generated sections, taxonomies, and pages before upload.
- A pipeline engineer would review the recipe's Zola version, output path, CLI provenance, CI caching, and failure policy before standardizing it.

## Installation

Not installable: Zola integration has no qualifying public implementation or package in the canonical Ariada repository.
