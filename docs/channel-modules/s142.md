# S142: Carrd integration

Carrd publishes compact responsive sites from sections, text, media, buttons, embeds, and forms, often behind a custom domain; a prospective Carrd integration would review the concrete one-page site assembled by solo creators and campaign owners.

## Boundary

The integration would scan a supplied preview or published URL without editing the Carrd design, form provider, embed, or domain. Third-party widgets would require separate access, and no current implementation would be implied.

## Roles

- Carrd site owner
- Campaign landing-page reviewer

## Use cases

- Before pointing an ad at a Carrd landing page, the reviewer would check section landmarks, button labels, contrast, and the complete form error path.
- After adding an embedded booking widget, the site owner would distinguish findings in Carrd-authored content from behavior controlled by the external embed.

## Installation

Not installable: Carrd integration has no qualifying public implementation or package in the canonical Ariada repository.
