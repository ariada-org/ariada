# S212: Substack publication/post scan recipe

Substack publishes each post as an email and a web archive entry within a publication homepage, with discovery through subscriptions, recommendations, and shared links; a planned scan recipe would support authors and publication editors.

## Boundary

The recipe would not access subscriber data, publish or edit posts, control recommendation discovery, or guarantee how every inbox renders a message. It would be editorial guidance or a future workflow, not a Substack integration claim.

## Roles

- Substack publication editor
- Independent newsletter author

## Use cases

- Before publishing a Substack post, the author would review its web preview and test email for heading hierarchy, link wording, image descriptions, and readable embeds.
- The publication editor would inspect the homepage, archive, subscribe prompt, and post page after a theme or navigation change, keeping platform-owned controls distinct.

## Installation

Not installable: Substack publication/post scan recipe has no qualifying public implementation or package in the canonical Ariada repository.
