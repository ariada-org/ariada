# S147: BigCommerce app

BigCommerce merchants manage catalog and storefront configuration in the control panel while shoppers encounter theme and headless storefront pages; a proposed BigCommerce app would present Ariada evidence for selected storefront URLs and preview themes.

## Boundary

The app would not alter products, checkout, themes, or store settings, and it could not certify third-party payment surfaces. It would require merchant-authorized targets and would not imply an approved BigCommerce Marketplace listing.

## Roles

- BigCommerce storefront manager
- Ecommerce theme agency reviewer

## Use cases

- Before promoting a BigCommerce theme from preview to live, the agency reviewer would assess product, category, cart, and search states populated with representative catalog data.
- The storefront manager would examine an Ariada finding on a product option and decide whether remediation belongs in theme markup, app-injected content, or catalog copy.

## Installation

Not installable: BigCommerce app has no qualifying public implementation or package in the canonical Ariada repository.
