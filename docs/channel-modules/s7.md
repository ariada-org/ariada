# S7: Drupal module

A proposed Drupal module would be a Drupal.org project and Composer-installable extension used by site builders and editors to review rendered nodes, Views, and theme output from within a Drupal publishing workflow.

## Boundary

There is no Drupal module release; any future module would surface findings for configured previews or URLs, not edit entities, bypass revisions and moderation, publish content, or claim that a Drupal site is compliant.

## Roles

- Drupal site builder
- Drupal editorial accessibility coordinator

## Use cases

- An editor would open the latest revision of a landing page, render its preview with the active theme, and inspect findings before moving it through content moderation.
- A site builder would evaluate the module's Drupal.org project, Composer constraints, permissions, and security coverage before enabling it on a staging site.

## Installation

Not installable: Drupal module has no qualifying public implementation or package in the canonical Ariada repository.
