# S220: LearnDash (WordPress LMS) add-on

LearnDash adds courses, lessons, topics, quizzes, and progression controls to WordPress sites, inheriting behavior from themes and other plugins; a proposed add-on would support Ariada review for course owners and WordPress developers.

## Boundary

The add-on would not change learner progress, quiz grades, WordPress content, themes, or plugin settings, and could not guarantee third-party components. It would not imply an installable LearnDash add-on.

## Roles

- LearnDash curriculum publisher
- WordPress LMS developer

## Use cases

- Before enrolling learners, the publisher would review a LearnDash course from registration through lesson navigation, quiz errors, feedback, and completion using a test account.
- The developer would examine findings across the active WordPress theme and LearnDash templates to identify whether remediation belongs to content, styling, or plugin customization.

## Installation

Not installable: LearnDash (WordPress LMS) add-on has no qualifying public implementation or package in the canonical Ariada repository.
