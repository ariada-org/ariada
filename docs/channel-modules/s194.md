# S194: Tauri integration

Tauri combines a web frontend in an operating-system WebView with Rust commands, native menus, and desktop packaging; a future Tauri integration would scope Ariada review to the rendered frontend while preserving desktop context.

## Boundary

The integration would not inspect Rust command safety, native menu accessibility, system dialogs, or WebView differences from one desktop scan. It would not modify Tauri configuration or claim an available plugin.

## Roles

- Tauri application developer
- Cross-platform desktop evaluator

## Use cases

- The developer would run a test build with representative Tauri frontend states and collect Ariada evidence for browser-based controls before packaging.
- The evaluator would repeat key flows on each supported operating system to cover WebView, focus, native-menu, and system-dialog behavior outside Ariada's web boundary.

## Installation

Not installable: Tauri integration has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence

- State: Planned
- Updated from evidence: Not available
- No qualifying public implementation evidence is declared and present on the canonical public tree.
