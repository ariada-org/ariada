# S133: Percy integration

Percy groups browser screenshots into builds and visual diffs that reviewers approve or request changes on; a prospective Percy integration would pair Ariada findings with the same snapshot names and build context used for visual review.

## Boundary

A pixel snapshot cannot reveal the full accessibility tree or keyboard behavior, so Ariada evidence would require a rendered test state rather than image analysis alone. The integration would not approve Percy diffs or imply current availability.

## Roles

- Visual regression reviewer
- Design quality engineer

## Use cases

- When Percy flags a changed modal snapshot, the reviewer would open the corresponding rendered state and examine Ariada evidence before approving a visually acceptable but semantically broken change.
- The quality engineer would group findings by Percy build and snapshot name so a responsive component regression can be assigned to the correct pull request.

## Installation

Not installable: Percy integration has no qualifying public implementation or package in the canonical Ariada repository.
