# S60: Sanity studio tool/plugin

A proposed Sanity plugin would be an npm package added to Studio configuration, contributing a document view or tool where editors and Studio developers could analyze the frontend preview for a selected document.

## Boundary

No Sanity Studio plugin is delivered; a future tool would need a configured preview resolver, would read only authorized document data, and would not patch documents, publish drafts, alter schema, or equate Studio structure with rendered accessibility.

## Roles

- Sanity Studio content editor
- Sanity schema and preview developer

## Use cases

- An editor would open a draft article's presentation preview and review findings before requesting editorial approval.
- A Studio developer would add the plugin in a test workspace and evaluate document locations, permissions, preview parameters, and npm compatibility.

## Installation

Not installable: Sanity studio tool/plugin has no qualifying public implementation or package in the canonical Ariada repository.
