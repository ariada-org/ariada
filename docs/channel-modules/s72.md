# S72: JSR (jsr.io) package publish

The proposed JSR release would be a scoped, versioned JavaScript or TypeScript package with declared exports and generated documentation, discoverable by Deno and other JSR-compatible consumers.

## Boundary

No JSR package or scope publication is asserted; a registry release would distribute only code that already exists and has a truthful runtime contract, not create a hosted scan service, guarantee cross-runtime support, or certify results.

## Roles

- JSR package release publisher
- Deno tooling integration developer

## Use cases

- A Deno project would import a pinned JSR version and invoke its documented API against an explicitly supplied target.
- A publisher would verify exports, runtime permissions, documentation, provenance, versioning, and scope ownership before issuing a JSR release.

## Installation

Not installable: JSR (jsr.io) package publish has no qualifying public implementation or package in the canonical Ariada repository.
