# S229: Rush plugin

Rush manages large JavaScript monorepos through projects, phased commands, version policies, change files, and controlled publishing; a planned Rush plugin would integrate Ariada review into a declared command phase for deployable web projects.

## Boundary

The plugin would not version or publish packages, rewrite Rush configuration, or scan libraries that have no rendered test surface. It would remain a proposal without a Rush plugin package or command implementation claim.

## Roles

- Rush repository administrator
- Monorepo release policy engineer

## Use cases

- A repository administrator would attach a proposed Ariada operation to a phased command after documentation and demo sites become reachable.
- The policy engineer would select affected deployable projects and preserve evidence by change set, avoiding a repository-wide block for unrelated packages.

## Installation

Not installable: Rush plugin has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence

- State: Planned
- Updated from evidence: Not available
- No qualifying public implementation evidence is declared and present on the canonical public tree.
