# S114: GitBook integration

The proposed GitBook integration would be an app installed into an organization or space and discovered through GitBook's integrations surface, helping workspace editors review published or authorized preview documentation URLs.

## Boundary

No GitBook app or listing exists; a future integration would use only supported app scopes and reachable page surfaces, would not edit or publish space content, change members, or assume access to private previews without authorization.

## Roles

- GitBook space content editor
- GitBook organization app administrator

## Use cases

- An editor would request analysis of a change-request preview and inspect navigation, callouts, tabs, and embedded content before merging it.
- An administrator would review requested scopes, app hosting, webhooks, private-space handling, data retention, and listing disclosures before installation.

## Installation

Not installable: GitBook integration has no qualifying public implementation or package in the canonical Ariada repository.
