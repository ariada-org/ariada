# S227: Nx plugin

Nx plugins can contribute generators, executors, project-graph logic, and inferred tasks across a monorepo; a planned Nx plugin would let workspace teams invoke Ariada review as an explicit target with normal task inputs and outputs.

## Boundary

The plugin would not alter Nx scheduling, bypass affected-project logic, publish packages, or guarantee coverage beyond configured targets. It would not imply an npm package, executor schema, or implemented cache contract.

## Roles

- Nx workspace architect
- Project-graph tooling engineer

## Use cases

- A workspace architect would configure a proposed Ariada target for deployable web apps and run it only where Nx identifies relevant affected projects.
- The tooling engineer would define cache inputs around built content, configuration, and target URL so stale findings are not replayed for a materially different preview.

## Installation

Not installable: Nx plugin has no qualifying public implementation or package in the canonical Ariada repository.
