# S123: ProtoPie plugin

ProtoPie creators build high-fidelity interactions from scenes, layers, variables, sensors, and device responses; a prospective ProtoPie plugin would let motion designers associate Ariada observations with the exact prototype scene being reviewed.

## Boundary

Ariada would not claim to interpret every sensor, formula, voice, or native-device behavior in a ProtoPie prototype. The plugin would preserve human review of interaction intent, leave prototype files unchanged, and remain explicitly planned.

## Roles

- Interaction motion designer
- Prototype test moderator

## Use cases

- Before a ProtoPie Cloud test session, the moderator would review the scene sequence for focus order, non-motion alternatives, and instructions that do not rely on gesture alone.
- When a designer publishes a revised microinteraction, they would link an Ariada observation to the affected layer and document a reduced-motion expectation for engineering.

## Installation

Not installable: ProtoPie plugin has no qualifying public implementation or package in the canonical Ariada repository.
