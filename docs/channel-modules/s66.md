# S66: Payload CMS plugin

A future Payload CMS plugin would be an npm package added to Payload configuration, giving application developers and editorial teams an admin action linked to a draft's rendered preview.

## Boundary

No Payload plugin is available; a future integration would use configured access controls and preview URLs, would not change collections, hooks, drafts, or publication state, and would not claim that server data alone represents UI accessibility.

## Roles

- Payload application developer
- Payload editorial operations lead

## Use cases

- An editor would open a draft page's preview, scan the rendered frontend with its current block data, and review results before publishing.
- A developer would evaluate plugin configuration, admin-component placement, access-control behavior, package compatibility, and npm provenance before adoption.

## Installation

Not installable: Payload CMS plugin has no qualifying public implementation or package in the canonical Ariada repository.
