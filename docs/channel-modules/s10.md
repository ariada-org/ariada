# S10: Wix app

The proposed Wix app would be an App Market product authorized for a Wix site, where site owners and agency designers could request analysis of editor previews or published page URLs during site preparation.

## Boundary

No Wix app or App Market approval is claimed; a future app could use only Wix-supported APIs and granted site access, and it would not manipulate editor elements, publish the site, alter commerce data, or promise acceptance by Wix.

## Roles

- Wix agency site designer
- Small-business website owner

## Use cases

- A site designer would review a dynamic-page preview at desktop and mobile breakpoints before asking the owner to publish a redesign.
- An app publisher would document OAuth scopes, data handling, pricing, and a working demo for Wix App Market evaluation.

## Installation

Not installable: Wix app has no qualifying public implementation or package in the canonical Ariada repository.
