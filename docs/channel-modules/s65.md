# S65: Directus extension

A planned Directus extension would be an extension bundle installed into an instance, contributing an interface, module, panel, or operation chosen to fit the review workflow for collection editors.

## Boundary

No Directus extension bundle or registry listing exists; a future extension would access only permitted collections and project-defined preview URLs, would not alter items or flows, publish external sites, or interpret API records as rendered pages.

## Roles

- Directus collection editor
- Directus instance extension administrator

## Use cases

- An editor would launch the frontend preview for a draft item and review findings before changing its publication status.
- An administrator would inspect the bundle type, sandbox and endpoint permissions, compatible Directus versions, and installation path before enabling it.

## Installation

Not installable: Directus extension has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence

- State: Planned
- Updated from evidence: Not available
- No qualifying public implementation evidence is declared and present on the canonical public tree.
