# S218: Canvas LMS (LTI tool)

Canvas LMS launches external tools through LTI from courses, assignments, modules, or navigation, passing scoped context for instructors and learners; a proposed Canvas LMS (LTI tool) would present Ariada review evidence within an authorized course workflow.

## Boundary

The tool would not inspect all Canvas content, access grades or submissions without need, alter courses, or certify Canvas-owned UI. LTI launch context and permissions would stay scoped, and no registered tool is implied.

## Roles

- Canvas instructional designer
- LTI deployment administrator

## Use cases

- An instructional designer would launch the proposed tool from a draft Canvas module and review linked pages and resources as a learner would encounter them.
- The deployment administrator would verify LTI roles, deep links, iframe focus, and launch errors in a test course before any campus-wide configuration.

## Installation

Not installable: Canvas LMS (LTI tool) has no qualifying public implementation or package in the canonical Ariada repository.
