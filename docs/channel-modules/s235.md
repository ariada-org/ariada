# S235: Changesets / release hook

Changesets records release intent in change files and turns them into version updates and changelogs before workspace packages are published; a planned release hook would associate Ariada evidence with deployable component or site changes.

## Boundary

The hook would not create changesets, choose semantic versions, publish packages, or claim source-only package accessibility. It would keep review decisions explicit and would not imply an implemented Changesets plugin or hook package.

## Roles

- Changesets release planner
- Versioned UI package approver

## Use cases

- When a changeset affects a UI package, the approver would review its rendered examples and link Ariada evidence to the pending release plan.
- The release planner would distinguish blocking component regressions from documentation-only or non-rendered package changes before applying versions and generating changelogs.

## Installation

Not installable: Changesets / release hook has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence

- State: Planned
- Updated from evidence: Not available
- No qualifying public implementation evidence is declared and present on the canonical public tree.
