# S153: OpenCart extension

OpenCart extensions are discovered through its marketplace and installed into an administration-backed PHP storefront with catalog, theme, and checkout pages; a planned OpenCart extension would report Ariada evidence for merchant-selected routes.

## Boundary

The extension would not patch templates or extension modifications, alter catalog records, submit real orders, or guarantee compatibility with every theme. No marketplace publication or downloadable implementation would be implied.

## Roles

- OpenCart shop administrator
- PHP theme customizer

## Use cases

- After installing a new OpenCart theme, the customizer would review category filters, product options, cart updates, and account forms before switching the store to it.
- The shop administrator would use route and extension context to determine whether a finding originates in core checkout, theme markup, or a third-party module.

## Installation

Not installable: OpenCart extension has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence

- State: Planned
- Updated from evidence: Not available
- No qualifying public implementation evidence is declared and present on the canonical public tree.
