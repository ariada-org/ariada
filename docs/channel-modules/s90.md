# S90: MkDocs plugin

The planned MkDocs plugin would be a PyPI package registered through an entry point and enabled in `mkdocs.yml`, allowing docs authors to inspect the generated `site_dir` during a build.

## Boundary

No MkDocs plugin or package listing exists; a future plugin would analyze generated HTML without editing Markdown, navigation, or theme files, and would not publish the site or cover runtime states absent from static output.

## Roles

- MkDocs site configuration author
- Technical documentation release manager

## Use cases

- An author would build a Material-themed documentation site and review findings for navigation, search markup, and content pages before deployment.
- A release manager would inspect plugin entry points, MkDocs and theme versions, strict-mode behavior, configuration schema, and PyPI metadata.

## Installation

Not installable: MkDocs plugin has no qualifying public implementation or package in the canonical Ariada repository.
