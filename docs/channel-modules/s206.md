# S206: Plone (Python) add-on

Plone add-ons extend a Python CMS with content types, views, portlets, workflows, and control-panel settings, commonly distributed through Python packaging; a planned Plone add-on would support Ariada review of published and pending content.

## Boundary

The add-on would not mutate content, Dexterity schemas, workflows, permissions, or theme code and would not promise compatibility across all Plone versions. It would not imply a PyPI release or add-on registry entry.

## Roles

- Plone site administrator
- Dexterity content-type developer

## Use cases

- Before a Plone workflow transition publishes a page, the administrator would review its rendered view, portlets, and related-content navigation.
- The content-type developer would populate every significant field combination and use Ariada evidence to correct the view template rather than burdening individual authors.

## Installation

Not installable: Plone (Python) add-on has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence

- State: Planned
- Updated from evidence: Not available
- No qualifying public implementation evidence is declared and present on the canonical public tree.
