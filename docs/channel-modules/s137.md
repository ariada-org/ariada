# S137: Builder.io plugin

Builder.io stores visual pages and sections as model-based content entries that marketers compose and publish to connected sites; a planned Builder.io plugin would expose Ariada findings for the entry and preview being edited.

## Boundary

The plugin would assess a rendered preview, not guarantee every host application's rendering of the same entry. It would not publish Builder content, change targeting or scheduling, rewrite custom components, or imply an installed marketplace plugin.

## Roles

- Visual content producer
- Builder component developer

## Use cases

- Before scheduling a Builder.io campaign page, the producer would review the exact targeted variant for heading order, link purpose, and form instructions.
- When a custom Builder component enters the component registry, its developer would render representative inputs and use Ariada evidence to correct the host implementation.

## Installation

Not installable: Builder.io plugin has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence

- State: Planned
- Updated from evidence: Not available
- No qualifying public implementation evidence is declared and present on the canonical public tree.
