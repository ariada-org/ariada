# S161: Monday.com app

monday.com apps can add board views, item views, integrations, and automations around rows that teams use to manage launches; a planned Monday.com app would connect Ariada evidence with the relevant item and asset URL.

## Boundary

The app would not inspect a site through board data alone, alter columns or automations without consent, or decide release status. It would require scoped authorization and would not imply marketplace availability.

## Roles

- monday.com board architect
- Digital launch portfolio manager

## Use cases

- For each launch item, the portfolio manager would review Ariada evidence tied to the staged URL and route defects to the board's existing functional owners.
- The board architect would design an item view that distinguishes new, accepted, and resolved findings without reducing accessibility risk to a single opaque number.

## Installation

Not installable: Monday.com app has no qualifying public implementation or package in the canonical Ariada repository.
