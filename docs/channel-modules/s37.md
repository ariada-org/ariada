# S37: Babel plugin

A future Babel plugin would be an npm-distributed transform-stage package configured by JavaScript build teams to inspect accessibility-relevant JSX or template syntax as Babel traverses source ASTs.

## Boundary

No Babel plugin is published; any implementation would be static-source analysis unless a separate rendered scan is supplied, would avoid semantics-changing transforms, and could not observe computed layout, browser events, or runtime content.

## Roles

- Babel configuration platform engineer
- JSX component library author

## Use cases

- A component library would enable the plugin in a non-mutating analysis pass and review a source location reported during compilation.
- A build engineer would evaluate parser presets, Babel version compatibility, monorepo configuration, and package provenance before registry adoption.

## Installation

Not installable: Babel plugin has no qualifying public implementation or package in the canonical Ariada repository.
