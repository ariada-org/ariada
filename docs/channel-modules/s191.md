# S191: Cordova plugin

Cordova applications load HTML, CSS, and JavaScript in a native WebView and invoke device functionality through plugins; a proposed Cordova plugin would associate Ariada web-layer findings with legacy hybrid release testing.

## Boundary

The plugin would not establish accessibility of native dialogs, plugin UI, or platform-specific WebViews from a desktop scan. It would not patch application assets or claim availability in the Cordova ecosystem.

## Roles

- Cordova legacy-app engineer
- Hybrid regression test owner

## Use cases

- The engineer would review Cordova web assets after navigation and form states are rendered, then remediate shared HTML before producing platform builds.
- The test owner would verify each significant finding on supported devices because WebView versions and third-party Cordova plugins can alter focus and announcements.

## Installation

Not installable: Cordova plugin has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence

- State: Planned
- Updated from evidence: Not available
- No qualifying public implementation evidence is declared and present on the canonical public tree.
