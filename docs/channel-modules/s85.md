# S85: CodeSandbox / StackBlitz integration

The proposed integration would be a reusable CodeSandbox template or StackBlitz starter with declared dependencies and tasks, letting example authors and workshop participants run Ariada against the sandbox's rendered preview.

## Boundary

No template, starter, or platform partnership exists; a future example would operate within each sandbox's runtime and network limits, would not gain access to unrelated projects, and would demonstrate a workflow rather than certify hosted apps.

## Roles

- Interactive code-example author
- Frontend training workshop facilitator

## Use cases

- An example author would publish a forkable sandbox whose explicit scan command evaluates the current preview after a participant changes a component.
- A facilitator would verify dependency pinning, WebContainer or VM compatibility, preview-origin access, and reset behavior before sharing the starter.

## Installation

Not installable: CodeSandbox / StackBlitz integration has no qualifying public implementation or package in the canonical Ariada repository.

- No qualifying public implementation evidence is declared and present on the canonical public tree.
