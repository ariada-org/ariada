# S110: VuePress plugin

A future VuePress plugin would be an npm-distributed package enabled in VuePress configuration, giving theme developers and docs publishers a build-stage view of accessibility findings for generated routes.

## Boundary

No VuePress plugin is available; an eventual plugin would analyze declared output or previews without rewriting Markdown, theme components, or navigation, and would document whether it supports VuePress 1, VuePress 2, or both.

## Roles

- VuePress theme integration developer
- Vue-powered docs publishing owner

## Use cases

- A theme developer would build the docs site, scan the generated route set, and investigate a finding tied to custom theme navigation.
- A publishing owner would inspect VuePress generation support, plugin API version, locale handling, configuration, and package metadata before adoption.

## Installation

Not installable: VuePress plugin has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence

- State: Planned
- Updated from evidence: Not available
- No qualifying public implementation evidence is declared and present on the canonical public tree.
