# S113: mdBook preprocessor

A future mdBook distribution would be an installable preprocessor executable declared in `book.toml`, potentially collecting source-level evidence for Rust documentation authors alongside a separate rendered-HTML scan.

## Boundary

No preprocessor executable exists, and an mdBook preprocessor runs before the HTML renderer, so it cannot by itself validate the final DOM or theme; any proposal must distinguish pre-render analysis from a post-build scan and must not rewrite chapters silently.

## Roles

- mdBook documentation author
- Rust documentation toolchain engineer

## Use cases

- An author would configure a pinned preprocessor to report source-level concerns while building a book, then run a separate scan on `book/html` for rendered evidence.
- A toolchain engineer would review the JSON protocol, renderer selection, Cargo installation, version compatibility, failure behavior, and source-preservation guarantees.

## Installation

Not installable: mdBook preprocessor has no qualifying public implementation or package in the canonical Ariada repository.
