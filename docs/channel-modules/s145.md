# S145: Super.so (Notion-site) integration

Super.so turns selected Notion pages and databases into branded public websites with navigation, themes, and custom domains; a planned Super.so (Notion-site) integration would review the transformed web surface managed by publication owners.

## Boundary

Ariada would assess the rendered Super site, not private Notion content or the Notion editor. It would not change source pages, Super themes, DNS, or indexing and would not imply an active integration.

## Roles

- Notion-site publisher
- Knowledge-base experience owner

## Use cases

- Before exposing a Notion knowledge base through Super.so, the owner would review generated navigation, database views, headings, and image descriptions on representative pages.
- After changing a Super.so theme, the publisher would compare public pages with varied Notion block types and resolve template-wide contrast or focus regressions.

## Installation

Not installable: Super.so (Notion-site) integration has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence

- State: Planned
- Updated from evidence: Not available
- No qualifying public implementation evidence is declared and present on the canonical public tree.
