# S188: Expo plugin

Expo config plugins modify native project configuration during prebuild, while Expo projects may also publish web output and EAS previews; a planned Expo plugin would define a review implementation review for explicit web or test artifacts.

## Boundary

A config plugin cannot by itself evaluate a running native interface. Ariada would not claim native accessibility-tree access, alter app configuration silently, or equate Expo web results with iOS and Android behavior; the plugin remains proposed.

## Roles

- Expo application architect
- EAS release test lead

## Use cases

- For an Expo Router web preview, the test lead would review rendered routes with Ariada and keep those findings scoped to the browser target.
- Before any future config plugin enters prebuild, the architect would inspect its generated native changes and require separate VoiceOver and TalkBack evaluation of the resulting app.

## Installation

Not installable: Expo plugin has no qualifying public implementation or package in the canonical Ariada repository.
