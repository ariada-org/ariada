# S167: AWS Amplify integration

AWS Amplify builds and hosts frontend branches with deployment logs, environment variables, custom domains, and pull-request previews; a planned AWS Amplify integration would review a selected preview URL within the frontend release workflow.

## Boundary

The integration would not manage Amplify apps, domains, IAM, or build settings and would not infer accessibility from a successful build. It would require an explicit reachable target and would not imply an existing Amplify integration.

## Roles

- Amplify frontend owner
- Branch-preview release reviewer

## Use cases

- For an Amplify pull-request preview, the reviewer would collect Ariada evidence on changed routes before approving promotion to the production branch.
- The frontend owner would distinguish a failed review caused by preview authentication or deployment errors from findings in the rendered application itself.

## Installation

Not installable: AWS Amplify integration has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence

- State: Planned
- Updated from evidence: Not available
- No qualifying public implementation evidence is declared and present on the canonical public tree.
