# S70: Vercel Marketplace integration

A proposed Vercel integration would be a Marketplace product installed through OAuth on selected projects, using deployment events and preview URLs to provide accessibility evidence to project owners and release reviewers.

## Boundary

No Vercel integration or Marketplace listing exists; a future service would use only approved scopes and reachable deployments, would not change project settings or production aliases, and could not scan protected previews without explicit authorized access.

## Roles

- Vercel project owner
- Preview-deployment quality reviewer

## Use cases

- A project owner would install the integration on one application and authorize it to analyze preview deployments before promotion.
- A quality reviewer would open the report linked to a deployment event and decide whether the existing Vercel release process should proceed.

## Installation

Not installable: Vercel Marketplace integration has no qualifying public implementation or package in the canonical Ariada repository.
