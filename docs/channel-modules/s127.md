# S127: Cypress plugin

Cypress runs browser tests from specs against a live DOM and records command logs, screenshots, videos, and CI results; a planned Cypress plugin would add Ariada accessibility evidence for test authors and release engineers.

## Boundary

The plugin would evaluate pages reached by configured Cypress tests, not replace assertions or guarantee coverage of unvisited states. It would neither repair application code nor imply a published Cypress package or service.

## Roles

- Cypress test author
- Web release engineer

## Use cases

- A test author would add an Ariada review point after Cypress opens a populated account dialog, preserving findings with that CI run rather than scanning only the empty page.
- Before release, the engineer would compare findings from Cypress specs covering anonymous and signed-in routes and triage regressions against the responsible feature team.

## Installation

Not installable: Cypress plugin has no qualifying public implementation or package in the canonical Ariada repository.
