# S139: Webstudio integration

Webstudio creators assemble responsive sites from components, style sources, and project pages before publishing them to a domain or export target; a future Webstudio integration would place Ariada evidence in that preview-to-publish review loop.

## Boundary

The integration would analyze a specified rendered project URL and would not control Webstudio hosting, domains, exports, or project data. It would not repair styles automatically or claim that a connector currently exists.

## Roles

- Webstudio site creator
- Responsive layout auditor

## Use cases

- The site creator would review a Webstudio staging URL at narrow and wide viewports before connecting the production domain, resolving reflow and focus-visibility findings.
- After changing a shared navigation component, the layout auditor would sample pages that use it and avoid treating one clean page as proof for the entire project.

## Installation

Not installable: Webstudio integration has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence
