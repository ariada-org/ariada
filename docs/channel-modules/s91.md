# S91: JupyterLab extension

A proposed JupyterLab extension would be a prebuilt extension distributed through Python or JavaScript package channels and discoverable in approved Extension Manager environments, giving notebook authors a panel or command for rendered notebook content.

## Boundary

No JupyterLab extension is delivered; a future extension would inspect only notebook cells and outputs exposed to it, would not execute untrusted cells, change notebooks, administer JupyterHub, or guarantee coverage of custom widgets and canvas output.

## Roles

- Computational notebook author
- JupyterHub extension administrator

## Use cases

- A notebook author would render tables, charts, and Markdown explanations, then review findings before exporting or sharing the notebook.
- A JupyterHub administrator would assess prebuilt-extension compatibility, server requirements, permissions, package signing, and allow-list policy before deployment.

## Installation

Not installable: JupyterLab extension has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence
