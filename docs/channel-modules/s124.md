# S124: Lunacy plugin

Lunacy users assemble interface frames, reusable components, and prototypes in design documents and shared cloud projects; a planned Lunacy plugin would bring Ariada evidence into the review performed by interface designers and asset librarians.

## Boundary

The plugin would inspect only exported or rendered evidence made available to it. It would not edit design layers, validate an entire component library by inheritance, guarantee downstream code, or imply that Ariada currently ships for Lunacy.

## Roles

- Lunacy interface designer
- Shared asset librarian

## Use cases

- Before sharing a Lunacy cloud document, the interface designer would review key frames for text contrast, control labels, and reading sequence, then resolve findings in the source design.
- While curating a reusable Lunacy component set, the librarian would examine each interactive variant rather than assuming that one reviewed frame covers all states.

## Installation

Not installable: Lunacy plugin has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence

- State: Planned
