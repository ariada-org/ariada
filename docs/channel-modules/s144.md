# S144: Dorik integration

Dorik lets small teams assemble pages, reusable sections, CMS collection templates, and membership sites through a visual builder; a proposed Dorik integration would attach Ariada review evidence to the previewed page and content state.

## Boundary

The integration would not publish Dorik pages, alter CMS records, administer memberships, or guarantee third-party embeds. It would evaluate only supplied rendered states and would remain a proposed capability.

## Roles

- Dorik freelance builder
- Small-business web editor

## Use cases

- Before a Dorik CMS collection goes live, the editor would sample entries with short, long, and missing media content to expose template-level accessibility failures.
- The builder would review navigation and pricing sections in the Dorik preview at mobile width, resolving focus and reflow issues before connecting the client's domain.

## Installation

Not installable: Dorik integration has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence

- No qualifying public implementation evidence is declared and present on the canonical public tree.
