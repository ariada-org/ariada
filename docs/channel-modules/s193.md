# S193: Electron app integration

Electron applications render web content in Chromium renderer processes while also exposing native windows, menus, and operating-system integration; a proposed Electron app integration would review reachable renderer states for desktop teams.

## Boundary

Ariada would not cover Electron's native menus, system dialogs, embedded remote content, or every BrowserWindow merely by scanning one renderer. It would not alter packaged apps and would remain a planned integration.

## Roles

- Electron desktop engineer
- Desktop assistive-technology tester

## Use cases

- The engineer would expose main-window, settings, and modal renderer states in a test build and review their DOM semantics and keyboard paths with Ariada.
- The desktop tester would separately evaluate application menus, window switching, system dialogs, and screen-reader announcements in the packaged Electron app.

## Installation

Not installable: Electron app integration has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence

- State: Planned
- Updated from evidence: Not available
- No qualifying public implementation evidence is declared and present on the canonical public tree.
