# S14: Sketch plugin

The planned Sketch plugin would be a signed plugin bundle distributed directly or through Sketch's plugin directory, used by interface designers and library owners to inspect selected artboards, symbols, and overrides.

## Boundary

No Sketch bundle or directory entry is provided; a future plugin would analyze accessible document objects without changing shared libraries, exporting assets, publishing documents, or treating static artboards as proof of implemented accessibility.

## Roles

- Sketch interface designer
- Shared-library release owner

## Use cases

- A library owner would compare states and overrides for a form-control symbol before releasing an updated library document.
- A plugin distributor would verify code signing, supported Sketch versions, update metadata, and sandbox permissions before directory submission.

## Installation

Not installable: Sketch plugin has no qualifying public implementation or package in the canonical Ariada repository.
