# S202: ProcessWire module

ProcessWire models sites through pages, fields, templates, and modules managed in its admin, with PHP templates producing the frontend; a planned ProcessWire module would connect Ariada findings to that concrete page-template relationship.

## Boundary

The module would not write page fields, install modules, modify PHP templates, or bypass admin access controls. It would review rendered URLs only and would not imply inclusion in the ProcessWire modules directory.

## Roles

- ProcessWire site architect
- Field-schema content manager

## Use cases

- The architect would sample ProcessWire pages for every frontend template after changing a shared navigation or form module.
- The content manager would inspect findings against populated field values and correct missing alternatives or unclear labels without assuming all defects are editorial.

## Installation

Not installable: ProcessWire module has no qualifying public implementation or package in the canonical Ariada repository.
