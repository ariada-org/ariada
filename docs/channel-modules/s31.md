# S31: Jenkins plugin

A proposed Jenkins plugin would be packaged as an HPI or JPI and distributed through an update site, adding a pipeline step and build-action report for Jenkins administrators and release teams.

## Boundary

No Jenkins plugin or update-center release exists; a future step would analyze configured artifacts or URLs while Jenkins retains control of agents, credentials, approvals, retention, and the final build result.

## Roles

- Jenkins controller administrator
- Pipeline quality-gate designer

## Use cases

- A pipeline author would run the scan after assembling a static site and archive the report from the same Jenkins build.
- A controller administrator would test the HPI in a staging controller, review required permissions and dependencies, and approve it through the organization's plugin process.

## Installation

Not installable: Jenkins plugin has no qualifying public implementation or package in the canonical Ariada repository.
