# S177: axe-core custom ruleset published to npm

axe-core custom rulesets are JavaScript configuration and rule code consumed by axe-based runners, with npm serving as the package discovery and version distribution surface; a planned Ariada ruleset would target teams extending existing test stacks.

## Boundary

A custom ruleset would not become part of axe-core, replace its supported rules, or justify claims beyond the checks it defines. Ariada would not imply that any npm package, namespace, or compatible rule bundle has been published.

## Roles

- Accessibility rule engineer
- npm dependency assessor

## Use cases

- Before adopting a future ruleset, the dependency assessor would inspect its documented rules, versions, and provenance rather than trusting a similarly named npm result.
- The rule engineer would run proposed Ariada-specific checks beside upstream axe results and keep rule identifiers distinct so consumers can interpret ownership and limitations.

## Installation

Not installable: axe-core custom ruleset published to npm has no qualifying public implementation or package in the canonical Ariada repository.
