# S18: Astro integration

The source-delivered Astro integration runs after an Astro build and writes accessibility reports for generated HTML, giving static-site engineers and deployment owners evidence tied to the built site artifact.

## Boundary

The integration supports Astro 4 or newer build completion from source but has no proven registry release; it sees generated output rather than unpublished editor state, authenticated runtime variants, or every client-side interaction.

## Roles

- Astro static-site engineer
- Content deployment approver

## Use cases

- An engineer builds a documentation site and reviews the report associated with its generated HTML before uploading the output.
- A deployment approver compares findings from the candidate Astro artifact with the release threshold before allowing the hosting job to continue.

## Installation

Source-delivered, not registry-published: build @ariada-org/astro with `pnpm --dir packages/ariada-astro run build`; the manifest does not prove an npm release.
