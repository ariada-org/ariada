# S118: Penpot plugin

A future Penpot plugin would be a manifest-addressed plugin installed into Penpot and potentially discovered through its plugin ecosystem, giving open-design teams a tool for reviewing selected boards, shapes, components, and design tokens.

## Boundary

No Penpot plugin or directory entry exists; a future plugin would use only the Penpot plugin API and user-approved file context, would not silently change shared components or libraries, publish files, or treat designs as proof of coded accessibility.

## Roles

- Penpot product interface designer
- Open-source design-system contributor

## Use cases

- A contributor would select component variants and boards, review reported structure and visual concerns, and discuss them before merging a shared-library change.
- A workspace team would inspect the plugin manifest URL, permissions, supported Penpot version, source provenance, and update path before installation.

## Installation

Not installable: Penpot plugin has no qualifying public implementation or package in the canonical Ariada repository.
