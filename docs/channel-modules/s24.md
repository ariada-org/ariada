# S24: Zed editor extension

The proposed Zed extension would be a registry-discoverable extension manifest and source repository that editor users install to invoke Ariada against workspace files or a configured local target.

## Boundary

No Zed extension or registry submission is present; implementation would depend on supported Zed extension APIs and could not claim diagnostics, command execution, network access, or automatic edits beyond capabilities actually granted by the editor.

## Roles

- Zed workspace developer
- Zed extension registry evaluator

## Use cases

- A developer would install the extension from Zed's Extensions view and invoke a scan while editing a web template.
- A registry evaluator would inspect the extension manifest, source repository, permissions, platform support, and update path before accepting a release.

## Installation

Not installable: Zed editor extension has no qualifying public implementation or package in the canonical Ariada repository.
