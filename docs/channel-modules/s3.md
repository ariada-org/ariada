# S3: MCP registry packaging for the MCP server

The source-delivered MCP server exposes scanning, rule lookup, violation explanation, and fix-suggestion tools to MCP-capable coding hosts; registry metadata would be the discovery object for broader host installation.

## Boundary

The server exists in source, but no MCP registry or package-registry publication is asserted; hosts decide permissions and tool invocation, and suggestions neither edit code automatically nor certify a result.

## Roles

- MCP host integration administrator
- AI-assisted accessibility investigator

## Use cases

- A host administrator registers the stdio server in an MCP client and verifies the declared tools before enabling them for a development team.
- A developer scans a supplied target, asks for the rule behind one violation, and evaluates the suggested remediation before making a code change.

## Installation

Source-delivered, not registry-published: build @ariada-org/mcp-server with `pnpm --dir packages/ariada-mcp-server run build`; no npm or MCP registry release is claimed.
