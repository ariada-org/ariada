# S58: Ghost integration

A future Ghost integration would be configured through Ghost's integrations surface and APIs, allowing publication teams to submit post previews or rendered site URLs for analysis around the editorial workflow.

## Boundary

No Ghost integration or marketplace resource exists; a future connection would use only granted Content or Admin API access and reachable previews, would not edit members or posts, publish drafts, change themes, or treat API content as rendered UI.

## Roles

- Ghost publication editor
- Ghost integration security administrator

## Use cases

- An editor would render a newsletter post on the active theme and review headings, links, images, and signup elements before publication.
- An administrator would create narrowly scoped integration credentials, verify webhook or preview behavior, and assess data retention before enabling it.

## Installation

Not installable: Ghost integration has no qualifying public implementation or package in the canonical Ariada repository.
