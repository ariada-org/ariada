# S57: WordPress.org core plugin (general site-scan)

The proposed general WordPress plugin would be a directory-listed ZIP installed from wp-admin, giving site administrators and plugin reviewers a way to scan configured public or previewable site URLs across themes and content types.

## Boundary

No WordPress.org plugin or SVN release exists; a future scanner would not modify posts, themes, plugins, users, or publication state, and private previews would require explicit authorized access rather than an assumed crawl.

## Roles

- WordPress multisite administrator
- WordPress Plugin Directory evaluator

## Use cases

- An administrator would scan representative posts, archive pages, navigation, search, and form states on staging before a theme launch.
- A directory evaluator would inspect readme claims, capabilities, nonce and permission handling, data collection, and supported WordPress versions before approval.

## Installation

Not installable: WordPress.org core plugin (general site-scan) has no qualifying public implementation or package in the canonical Ariada repository.
