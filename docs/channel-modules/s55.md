# S55: Eleventy (11ty) plugin

A future Eleventy plugin would be an npm package registered through the Eleventy configuration API, used by static-site authors to scan generated HTML in the output directory after templates and data have resolved.

## Boundary

No Eleventy plugin is published; a future hook would read generated pages without rewriting content, would leave deployment to the site build, and could not evaluate browser-only interactions absent from static output.

## Roles

- Eleventy site author
- Static publishing workflow editor

## Use cases

- A site author would build multilingual collections and review findings for the generated pagination and navigation pages before upload.
- A workflow editor would inspect plugin registration, Eleventy version support, output-directory handling, and npm metadata before adding it to configuration.

## Installation

Not installable: Eleventy (11ty) plugin has no qualifying public implementation or package in the canonical Ariada repository.
