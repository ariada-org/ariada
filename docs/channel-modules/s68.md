# S68: Bitbucket Pipe

A future Bitbucket Pipe would be a versioned container with a `pipe.yml` contract referenced from Bitbucket Pipelines, giving repository teams a reusable scan step discoverable through Atlassian's pipe ecosystem.

## Boundary

No Pipe image, repository, or directory listing exists; a future Pipe would process explicit artifacts or URLs and return results while Bitbucket controls variables, runners, permissions, merge checks, and deployments.

## Roles

- Bitbucket Pipelines configuration author
- Atlassian workspace security administrator

## Use cases

- A repository would call a digest- or tag-pinned Pipe after building its site and upload the report from the pipeline step.
- A workspace administrator would examine image source, variables, secret exposure, network behavior, and vendor-listing information before allowing use.

## Installation

Not installable: Bitbucket Pipe has no qualifying public implementation or package in the canonical Ariada repository.
