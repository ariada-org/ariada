# S28: Neovim/Vim plugin

The proposed Neovim/Vim plugin would be a versioned Git repository installed by editor plugin managers, exposing commands and quickfix or diagnostic entries to terminal-focused web developers.

## Boundary

No Vimscript or Lua plugin is delivered; a future integration would require an explicitly configured Ariada executable or service, would not modify buffers by default, and could assess only supplied source or reachable rendered targets.

## Roles

- Terminal-editor frontend developer
- Developer-environment configuration steward

## Use cases

- A Neovim user would invoke a buffer scan and move through findings using the diagnostic list while editing a component template.
- A dotfiles steward would pin a release tag, configure executable discovery and timeouts, and test behavior across Vim and Neovim before team adoption.

## Installation

Not installable: Neovim/Vim plugin has no qualifying public implementation or package in the canonical Ariada repository.
