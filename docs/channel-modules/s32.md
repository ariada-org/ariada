# S32: Azure DevOps extension

The planned Azure DevOps extension would be a VSIX listed in the Visual Studio Marketplace or shared privately to an organization, providing a pipeline task and result surface for Azure project teams.

## Boundary

No VSIX or Marketplace listing is delivered; a future task would process declared build artifacts or endpoints and publish evidence, without managing service connections, changing branch policies, approving environments, or controlling deployments.

## Roles

- Azure DevOps organization administrator
- YAML pipeline accessibility engineer

## Use cases

- A pipeline engineer would add the task after a web build, pass the artifact directory, and attach findings to the run summary.
- An organization administrator would review publisher identity, extension scopes, task inputs, and private sharing behavior before installation.

## Installation

Not installable: Azure DevOps extension has no qualifying public implementation or package in the canonical Ariada repository.
