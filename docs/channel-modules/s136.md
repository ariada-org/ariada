# S136: Sauce Labs integration

Sauce Labs organizes automated tests into jobs and builds with browser capabilities, logs, videos, and screenshots; a future Sauce Labs integration would connect Ariada evidence to those records for cloud-test reviewers.

## Boundary

Ariada would neither schedule Sauce Labs capacity nor assert native-app coverage from a web session. The integration would be confined to configured, reachable web content, would make no automatic fixes, and would not imply deployment.

## Roles

- Sauce test program owner
- Cloud execution diagnostician

## Use cases

- For a failed Sauce job, the diagnostician would inspect session logs and Ariada evidence together to determine whether navigation failed before the intended state was scanned.
- The program owner would compare release builds by named Sauce capability and route a focus-order regression only after reproducing it in the matching browser.

## Installation

Not installable: Sauce Labs integration has no qualifying public implementation or package in the canonical Ariada repository.
