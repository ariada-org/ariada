# S67: GitLab CI/CD Component (GitLab CI Catalog)

The proposed GitLab CI/CD Component would be a versioned component project released to the CI/CD Catalog, where pipeline authors could include it by reference and pass a generated site or authorized URL through declared inputs.

## Boundary

No catalog component or GitLab release exists; a future component would define a scan job while GitLab continues to own runners, variables, artifacts, merge-request status, protected environments, and deployment approval.

## Roles

- GitLab CI component publisher
- GitLab pipeline catalog consumer

## Use cases

- A pipeline author would include a pinned component release, supply the build directory, and expose the report in the merge-request pipeline.
- A component publisher would validate `spec:inputs`, runner assumptions, image provenance, version tags, and Catalog release metadata before publication.

## Installation

Not installable: GitLab CI/CD Component (GitLab CI Catalog) has no qualifying public implementation or package in the canonical Ariada repository.
