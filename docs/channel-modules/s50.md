# S50: Gatsby plugin

A proposed Gatsby plugin would be distributed through npm and surfaced in the Gatsby Plugin Library, where site engineers could configure post-build analysis of HTML in the `public` output.

## Boundary

No Gatsby plugin or library entry exists; a future plugin would scan generated pages and declared previews, not change GraphQL data, page creation, themes, or deployment, and it would not cover client-only states absent from the build.

## Roles

- Gatsby site build engineer
- Content-site deployment owner

## Use cases

- A site engineer would add the plugin to Gatsby configuration and scan localized pages in `public` after a production build.
- A deployment owner would evaluate plugin options, Gatsby version support, build-time cost, report retention, and directory metadata before adoption.

## Installation

Not installable: Gatsby plugin has no qualifying public implementation or package in the canonical Ariada repository.
