# S190: Capacitor plugin

Capacitor packages a web application inside native iOS and Android projects and exposes device capabilities through plugins; a planned Capacitor plugin would connect Ariada review of web assets to the hybrid release record.

## Boundary

Ariada would inspect only the web layer it can reach and would not validate native plugin dialogs, platform controls, or accessibility trees. It would not modify Capacitor projects or imply a published plugin.

## Roles

- Capacitor platform engineer
- Mobile WebView validation lead

## Use cases

- Before a Capacitor build, the platform engineer would review the bundled web application's routes and interactive states in a representative browser environment.
- The validation lead would retest focus, zoom, keyboard, and screen-reader behavior in each packaged WebView where native chrome and plugins can change the experience.

## Installation

Not installable: Capacitor plugin has no qualifying public implementation or package in the canonical Ariada repository.
