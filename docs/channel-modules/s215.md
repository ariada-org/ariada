# S215: MailerLite landing/email scan recipe

MailerLite users publish campaigns, automation emails, forms, websites, and landing pages from visual editors; a proposed MailerLite landing/email scan recipe would split review by the actual email or hosted web object being released.

## Boundary

The recipe would not access subscriber groups, activate automations, send mail, edit sites, or promise consistent email-client rendering. It would describe review steps without asserting an available MailerLite connector.

## Roles

- MailerLite automation editor
- Small-publisher web reviewer

## Use cases

- An automation editor would test every MailerLite sequence message with representative merge fields and inspect structure, links, alternatives, and plain-text fallback before activation.
- The web reviewer would separately complete a MailerLite landing page and embedded form flow using keyboard and zoom, including error and success feedback.

## Installation

Not installable: MailerLite landing/email scan recipe has no qualifying public implementation or package in the canonical Ariada repository.
