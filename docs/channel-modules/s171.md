# S171: Terraform provider

Terraform providers expose resources and data sources whose desired state is reviewed in plans and recorded in state; a proposed Terraform provider would model Ariada review requests and results for infrastructure teams needing declarative orchestration.

## Boundary

Accessibility findings are observations, not infrastructure state that Terraform can safely remediate. The provider would not crawl undeclared targets, edit application code, manage unrelated cloud resources, or imply a published provider binary.

## Roles

- Terraform platform engineer
- Infrastructure plan approver

## Use cases

- A platform engineer would declare a review target for a newly provisioned documentation site and expose the resulting evidence without storing sensitive page content in Terraform state.
- The plan approver would distinguish creation of a review request from the later human decision about findings, avoiding perpetual diffs based on mutable observations.

## Installation

Not installable: Terraform provider has no qualifying public implementation or package in the canonical Ariada repository.
