# S22: Docker image (GHCR + Docker Hub)

The planned container distribution would publish versioned OCI images to GitHub Container Registry and Docker Hub for CI operators and platform teams that need a reproducible Ariada command environment.

## Boundary

No image, tag, digest, or registry page is available; a future container would package declared scanner behavior only, while callers remain responsible for mounts, network access, target authorization, secret handling, and interpretation of results.

## Roles

- Container-platform pipeline engineer
- Supply-chain image reviewer

## Use cases

- A pipeline engineer would pull a digest-pinned image, mount a generated site read-only, and retain the resulting report as a build artifact.
- An image reviewer would compare architectures, base-image provenance, labels, SBOM, signatures, and vulnerability results before approving mirrored use.
