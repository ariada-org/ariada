# S132: Lighthouse CI integration

Lighthouse CI collects Lighthouse runs, assertions, and historical build comparisons for deployed or locally served pages; a planned Lighthouse CI integration would add Ariada evidence to the performance and quality gate release teams already inspect.

## Boundary

The integration would not alter Lighthouse scores, present Ariada findings as Lighthouse audits, or claim complete application coverage from sampled URLs. It would publish no status unless configured and would not imply existing delivery.

## Roles

- Web performance budget owner
- Continuous-delivery gatekeeper

## Use cases

- For a pull-request preview, the gatekeeper would review Ariada evidence alongside Lighthouse CI assertions and distinguish an accessibility regression from a performance-budget failure.
- The budget owner would schedule representative authenticated and public URLs rather than treating a single Lighthouse CI home-page run as site-wide evidence.

## Installation

Not installable: Lighthouse CI integration has no qualifying public implementation or package in the canonical Ariada repository.

## Evidence

- State: Planned
- Updated from evidence: Not available
- No qualifying public implementation evidence is declared and present on the canonical public tree.
