Active domain modules

    Add a domain module

    Enter a published ariada-domain-* package name (installed via the companion command-line tool) or a path to a local .js/.mjs file (loaded in a sandbox). Remote URLs are not accepted.

    How modules load

    Companion CLI (full trust)
    The command-line tool rebuilds the extension with the module bundled in. The module runs at full extension trust and joins the single shared scan pass.
    Local file (sandboxed, lower trust)
    A local file runs inside a sandboxed frame with no access to Chrome APIs or your browsing data. Its results are marked with a warning badge. (This path is a documented stub in v0.1 — the validation and labelling are wired; the sandbox bridge lands in v0.2.)
    Remote URL (rejected)
    Loading a module from an http/https URL is rejected. Chrome Web Store policy prohibits fetching and executing remotely hosted code.
