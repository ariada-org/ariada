session_id cookie with neither Secure nor HttpOnly — transmittable over plain HTTP and accessible to JavaScript, making it vulnerable to both network interception and XSS.

auth_token cookie has HttpOnly set but not Secure — can be transmitted over an unencrypted HTTP connection.

_analytics cookie has Secure set but not HttpOnly — JavaScript on the page can read this value, exposing it to XSS attacks.

session_id cookie with both Secure and HttpOnly set — only transmitted over HTTPS and not accessible from JavaScript.

Page sets no cookies — the cookie loop in the extractor finds nothing to flag.
