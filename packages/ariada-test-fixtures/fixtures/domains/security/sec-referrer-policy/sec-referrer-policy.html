No Referrer-Policy header — browser uses its own default (often strict-origin-when-cross-origin in modern browsers, but older browsers may send the full URL).

Referrer-Policy: unsafe-url — sends the full URL (including path and query string) to all origins, leaking sensitive URL parameters.

Referrer-Policy: strict-origin-when-cross-origin — recommended value; sends origin only to cross-origin requests.

Referrer-Policy: no-referrer — maximally restrictive; passes because it is not absent and not 'unsafe-url'.

Referrer-Policy: same-origin — present and not 'unsafe-url'; passes.
