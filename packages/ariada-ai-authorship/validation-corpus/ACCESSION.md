# validation-corpus — accession

The validation corpus exceeds practical git-repo storage. The OSS-eligible
split is distributed via external storage with SHA-256-pinned tarballs;
the closed split is access-controlled and is not part of this OSS package.

The accession URLs and per-tarball checksums are published with each
release of the validation harness (forthcoming). When you run the harness
locally it will verify each downloaded tarball against the recorded
checksum before producing a reproducibility receipt.

The OSS-eligible split covers permissive-licence and CC0 source datasets;
the closed split additionally covers proprietary and licence-restricted
derivations used for held-out evaluation.
