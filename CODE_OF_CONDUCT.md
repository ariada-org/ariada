# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short — be respectful, professional, and welcoming. The full text of the Covenant defines what that means in practice and the consequences for violations.

## Reporting

To report an incident in this project's community spaces (GitHub issues, PRs, discussions, project Discord/Slack if any), email **conduct@ariada.org**. Reports are handled privately by the project maintainers.

Response targets:

| Event | Target |
|---|---|
| Acknowledge receipt of report | within 72 hours |
| Initial decision communicated | within 7 days |

## Scope

This applies to all project spaces: this GitHub repository (issues, PRs, discussions), npm package pages, project chat channels, and any in-person or virtual events organised by the maintainers.

## Maintainer enforcement

Maintainers will follow the Covenant's standard enforcement ladder:

1. Correction (private warning)
2. Warning (formal, with consequences for repeats)
3. Temporary ban
4. Permanent ban

Maintainers who do not follow or enforce this Code of Conduct in good faith may face temporary or permanent repercussions as determined by other members of the project's leadership.
