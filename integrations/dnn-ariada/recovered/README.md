# Ariada DNN runtime

This package is generated with npm `bundleDependencies`. Its packed manifest has
only exact semver dependencies and no lifecycle hooks, `file:` references, or
workspace references. It contains the real Ariada CLI, core compatibility layer,
core engine, Playwright adapter, Playwright packages, and axe analyzer.

Node 22 or later and the matching Playwright Chromium binary are host prerequisites.
No dependency installation is performed by the DNN web process.
