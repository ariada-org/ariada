# Concrete Ariada

Concrete CMS 9 package for displaying `@ariada-org/cli` accessibility results at
`Dashboard > System & Settings > Ariada Accessibility`.

The default mode reads `scan.json` from `application/files/ariada`. CLI mode is
explicit and starts the pinned Ariada CLI with a shell-free PHP argument list.
PHP itself does not crawl or scan a URL.

See the integration-level README before installation for prerequisites,
configuration, security boundaries, tests, and unresolved live-validation gates.
