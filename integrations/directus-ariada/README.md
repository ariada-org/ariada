# Ariada for Directus

Directus extension scaffold for item-level accessibility scans. The extension
maps a collection item to a rendered front-end URL and sends that URL to Ariada.

## Local Verification

```sh
pnpm --dir integrations/directus-ariada test
```

## Host Blocker

Extension load verification needs a Directus project, collections, item panel
mount, and marketplace account.
